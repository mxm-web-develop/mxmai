# 复杂图片生成的提示词工程方案

## 📋 方案概述

针对"描述详细、细节复杂、风格要求精确"的图片生成需求，设计一套系统化的提示词工程方案。

## 🎯 核心目标

1. **描述详细**：确保所有关键元素都被明确描述
2. **细节复杂**：处理多层次、多维度的细节信息
3. **风格精确**：精确控制艺术风格、技术参数、视觉氛围

## 🏗️ 方案架构

### 一、分层提示词结构（Layered Prompt Structure）

将提示词分为多个层次，逐层构建：

```
Layer 1: 核心意图层（Core Intent）
  ↓
Layer 2: 主体描述层（Subject Description）
  ↓
Layer 3: 环境场景层（Environment & Scene）
  ↓
Layer 4: 技术参数层（Technical Parameters）
  ↓
Layer 5: 风格控制层（Style Control）
  ↓
Layer 6: 细节补充层（Detail Enhancement）
```

#### 1.1 核心意图层（Core Intent）
- **作用**：明确用户想要生成什么
- **内容**：主体、动作、基本场景
- **示例**："生成一张年轻女性在咖啡厅工作的图像"

#### 1.2 主体描述层（Subject Description）
- **作用**：详细描述主要对象
- **维度**：
  - 外观特征（年龄、性别、体型、服装）
  - 姿态动作（坐姿、手势、表情）
  - 细节特征（发型、配饰、道具）
- **示例**："25岁亚洲女性，穿着米色针织衫和深色长裤，坐在木制椅子上，专注地看着笔记本电脑，长发披肩，戴着细框眼镜"

#### 1.3 环境场景层（Environment & Scene）
- **作用**：构建完整的场景环境
- **维度**：
  - 空间布局（室内/室外、房间类型、家具布置）
  - 背景元素（装饰、物品、建筑）
  - 环境氛围（时间、季节、天气）
- **示例**："现代简约风格的咖啡厅，浅色木地板，白色墙壁，落地窗，窗外是城市街道，下午3点，阳光透过百叶窗洒入，温暖的光线"

#### 1.4 技术参数层（Technical Parameters）
- **作用**：控制摄影/视觉技术参数
- **维度**：
  - 构图（镜头角度、焦距、景深）
  - 光线（光源方向、强度、色温）
  - 色彩（色调、饱和度、对比度）
- **示例**："中景镜头，35mm焦距，浅景深，从左侧窗户射入的柔和自然光，色温5500K，暖色调，高对比度"

#### 1.5 风格控制层（Style Control）
- **作用**：精确控制艺术风格
- **维度**：
  - 艺术风格（现实主义、印象派、插画、概念艺术）
  - 视觉风格（电影级、商业摄影、杂志风格）
  - 媒介质感（油画、水彩、数字绘画、摄影）
- **示例**："商业摄影风格，高清晰度，专业打光，浅色背景，产品级质感，现代简约美学"

#### 1.6 细节补充层（Detail Enhancement）
- **作用**：补充容易被忽略的细节
- **维度**：
  - 材质纹理（布料、金属、玻璃、木头的质感）
  - 光影细节（阴影、高光、反射）
  - 环境细节（空气中的尘埃、窗外的细节、背景的模糊程度）
- **示例**："针织衫有细腻的纹理，眼镜镜片有轻微反光，咖啡杯冒着热气，背景人物适度模糊，桌面有木纹质感"

### 二、提示词工程流程（Prompt Engineering Workflow）

#### 阶段1：需求分析（Requirement Analysis）

**输入**：用户的原始描述（可能是简单的一句话）

**处理步骤**：
1. **意图提取**：识别用户想要生成什么
2. **缺失检测**：分析哪些关键信息缺失
3. **复杂度评估**：判断需求的复杂程度
4. **模型适配**：根据需求特点推荐最适合的模型

**输出**：结构化的需求分析结果

**示例**：
```
用户输入："一个女孩在咖啡厅"
分析结果：
- 主体：女孩（缺少年龄、外观、服装）
- 动作：在咖啡厅（缺少具体行为）
- 场景：咖啡厅（缺少风格、布局、时间）
- 风格：未指定
- 技术参数：未指定
- 复杂度：中等（需要补充大量细节）
- 推荐模型：nano-banana（适合真实场景）或 seedream-4（适合电影级效果）
```

#### 阶段2：分层构建（Layered Construction）

**处理步骤**：
1. **逐层填充**：从核心意图层开始，逐层补充信息
2. **智能补全**：对于缺失的信息，使用默认值或推理补全
3. **一致性检查**：确保各层信息不冲突
4. **优先级排序**：重要信息优先，次要信息补充

**输出**：完整的六层提示词结构

#### 阶段3：细节增强（Detail Enhancement）

**处理步骤**：
1. **细节挖掘**：识别需要详细描述的关键元素
2. **感官描述**：添加视觉、触觉、氛围的细节
3. **材质纹理**：描述各种材质的具体质感
4. **光影细节**：精确描述光线和阴影

**输出**：增强后的详细提示词

#### 阶段4：风格精确化（Style Precision）

**处理步骤**：
1. **风格识别**：识别用户想要的风格类型
2. **风格参数化**：将抽象风格转化为具体参数
3. **技术术语**：使用专业术语精确描述
4. **参考对比**：与已知风格案例对比，确保准确性

**输出**：精确的风格描述

#### 阶段5：模型适配（Model Adaptation）

**处理步骤**：
1. **模型特性分析**：分析目标模型的特点
2. **提示词转换**：将通用提示词转换为模型特定格式
3. **优化调整**：根据模型特点优化提示词
4. **长度控制**：确保提示词长度在模型限制内

**输出**：针对特定模型优化的提示词

#### 阶段6：迭代优化（Iterative Refinement）

**处理步骤**：
1. **生成测试**：使用优化后的提示词生成图片
2. **结果分析**：分析生成结果与期望的差距
3. **问题识别**：识别哪些部分需要调整
4. **提示词修正**：针对性地修正提示词
5. **再次生成**：重复直到满意

**输出**：最终优化的提示词

### 三、细节补充机制（Detail Enhancement Mechanism）

#### 3.1 自动细节补全（Auto Detail Completion）

**原理**：基于常见场景的知识库，自动补充缺失的细节

**实现方式**：
- **场景模板库**：预定义常见场景的细节模板
- **推理引擎**：基于上下文推理缺失的细节
- **知识图谱**：使用知识图谱关联相关细节

**示例**：
```
输入："咖啡厅"
自动补全：
- 家具：木制桌椅、吧台、展示柜
- 装饰：绿植、艺术画、书架
- 氛围：温暖灯光、咖啡香气（视觉化）、舒适感
- 细节：咖啡杯、拉花、糕点、杂志、笔记本电脑
```

#### 3.2 感官细节增强（Sensory Detail Enhancement）

**原理**：从多个感官维度描述场景，增强真实感

**维度**：
- **视觉**：颜色、形状、纹理、光影
- **触觉**：材质质感、温度感
- **氛围**：情绪、氛围、时间感

**示例**：
```
基础："一张桌子"
增强："一张浅色橡木桌子，表面有细腻的木纹，触感温润，桌面上有咖啡杯留下的水渍痕迹，在柔和光线下呈现温暖的棕色调"
```

#### 3.3 材质纹理描述（Material Texture Description）

**原理**：精确描述各种材质的具体质感

**材质类型**：
- 布料：棉、丝、羊毛、皮革
- 金属：不锈钢、黄铜、铝
- 玻璃：透明、磨砂、有色
- 木头：原木、漆面、做旧
- 石头：大理石、花岗岩、混凝土

**描述模板**：
```
[材质类型] + [表面特征] + [质感] + [光泽度] + [颜色]
```

**示例**：
```
"深蓝色羊毛针织衫，细腻的编织纹理，柔软触感，哑光表面，在自然光下呈现深蓝到浅蓝的渐变"
```

### 四、风格精确化方法（Style Precision Methods）

#### 4.1 风格分类体系（Style Classification System）

**艺术风格分类**：
- 现实主义（Realism）
- 印象派（Impressionism）
- 超现实主义（Surrealism）
- 概念艺术（Concept Art）
- 插画风格（Illustration）
- 数字艺术（Digital Art）

**视觉风格分类**：
- 电影级（Cinematic）
- 商业摄影（Commercial Photography）
- 杂志风格（Magazine Style）
- 产品摄影（Product Photography）
- 人像摄影（Portrait Photography）
- 风景摄影（Landscape Photography）

#### 4.2 风格参数化（Style Parameterization）

**原理**：将抽象风格转化为可量化的参数

**参数维度**：
- **色彩**：色温、饱和度、对比度、色调
- **光线**：强度、方向、软硬、色温
- **构图**：比例、对称、黄金分割、三分法
- **质感**：锐度、模糊、噪点、纹理

**示例**：
```
风格："电影级"
参数化：
- 色温：5500K（自然光）
- 饱和度：中等偏高
- 对比度：高
- 色调：暖色调为主
- 光线：戏剧性侧光
- 构图：16:9宽屏比例
- 景深：浅景深，背景虚化
- 锐度：高清晰度
```

#### 4.3 风格参考对比（Style Reference Comparison）

**原理**：与已知风格案例对比，确保准确性

**实现方式**：
- **风格库**：建立风格案例库
- **相似度匹配**：找到最相似的风格案例
- **差异分析**：分析差异并调整
- **验证**：确保最终风格符合预期

### 六、迭代优化流程（Iterative Refinement Process）

#### 6.1 生成-分析-优化循环（Generate-Analyze-Optimize Loop）

```
生成图片
  ↓
分析结果
  ↓
识别问题
  ↓
修正提示词
  ↓
再次生成
  ↓
（重复直到满意）
```

#### 6.2 问题分类与修正（Problem Classification & Correction）

**问题类型**：
1. **主体问题**：主体不清晰、位置不对、大小不合适
2. **细节问题**：细节缺失、细节错误、细节不一致
3. **风格问题**：风格不符合、风格不统一、风格模糊
4. **技术问题**：光线不对、构图不佳、色彩偏差

**修正策略**：
- **主体问题** → 增强主体描述，明确位置和大小
- **细节问题** → 补充细节描述，修正错误细节
- **风格问题** → 明确风格参数，统一风格描述
- **技术问题** → 调整技术参数，精确描述光线和构图

#### 6.3 增量优化（Incremental Optimization）

**原理**：每次只优化一个问题，逐步改进

**步骤**：
1. 识别最严重的问题
2. 针对该问题修正提示词
3. 生成新图片
4. 评估改进效果
5. 重复直到所有问题解决
