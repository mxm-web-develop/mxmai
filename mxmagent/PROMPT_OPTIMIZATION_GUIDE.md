# 提示词优化指南：nano-banana、seedream-4 与 flux 模型对比

## 📋 核心结论

**重要区别**：
- **nano-banana** 和 **seedream-4**：**不需要**"魔法提示词"，理解自然语言
- **flux**：可能需要更结构化的提示词，但也不依赖"魔法提示词"

## 1. Nano-Banana (Gemini 3 Pro Image Preview)

### 特点
- ✅ **理解自然语言**：不需要"4K、masterpiece"等陈词滥调
- ✅ **基于推理能力**：使用 Gemini 3 的思考过程，在生成前优化构图
- ✅ **描述性优先**：越具体，越精确

### 提示词优化策略

#### 基本公式（适用于 80% 场景）
```
[生成/创建一张图像] + [主体 + 形容词] + [动作] + [场景/位置] + 
[构图/镜头] + [光线/氛围] + [风格/媒介] + [具体约束/文本]
```

#### 示例对比

❌ **避免**：
```
"4K masterpiece, best quality, highly detailed, a cat"
```

✅ **推荐**：
```
"生成一张猫在阳光下窗户边打盹的图像"
"生成一张穿着红裙的年轻女性在公园跑步的图像，中景镜头，柔和晨光，现实主义风格，背景有模糊的绿树"
```

#### 关键元素

1. **主体（Subject）**：具体描述
   - ❌ "一只猫"
   - ✅ "戴巫师帽的毛茸茸三色猫"

2. **动作（Action）**：明确行为
   - ❌ "在动"
   - ✅ "飞翔"、"冲泡咖啡"

3. **场景（Scene）**：具体位置
   - ❌ "在某个地方"
   - ✅ "太空中的木星背景"、"温馨客厅"

4. **构图（Composition）**：镜头角度
   - ✅ "特写"、"广角"、"低角度"

5. **光线/氛围（Lighting）**：具体描述
   - ✅ "金色夕阳"、"戏剧性 chiaroscuro 阴影"

6. **风格（Style）**：艺术形式
   - ✅ "油画"、"普普艺术"、"扁平插图"

#### 高级技巧

1. **整合真实世界知识**
   ```
   "生成一张关于艾萨克·牛顿光与色理论的现代扁平插图，使用真实科学数据"
   ```

2. **文本渲染**（nano-banana 的强项）
   ```
   "在标志上写'Banana Pro'用霜冻玻璃纹理的粗体 sans-serif 字体"
   ```

3. **图像编辑与迭代**
   ```
   先上传照片，然后"将天空换成黄昏，添加柔和阴影"
   ```

4. **光影控制**
   ```
   "从左侧柔和漫射光照射，焦点在花朵上"
   ```

## 2. Seedream-4 (ByteDance)

### 特点
- ✅ **理解自然语言**：不需要"魔法提示词"
- ✅ **电影级视觉效果**：擅长丰富的色彩分级和艺术风格
- ✅ **结构化提示词效果更好**：但不需要特定触发词

### 提示词优化策略

#### 结构化提示词模板

```
[主体] + [动作] + [环境] + [时间/天气] + [相机角度] + [艺术风格]
```

#### 示例

✅ **场景描述**：
```
"街头音乐家在繁忙的城市广场拉小提琴，金色时段光线，低角度拍摄，印象派绘画风格"
```

✅ **概念艺术**：
```
"科幻电影概念艺术，未来城市景观，飞行汽车，霓虹灯氛围，数字绘景"
```

✅ **产品拍摄**：
```
"豪华手表在大理石表面，戏剧性侧光，商业摄影风格，聚焦金属细节"
```

#### 优化流程

1. **从简单开始**：先写基础描述
2. **逐步添加细节**：环境 → 光线 → 角度 → 风格
3. **保持连贯性**：确保所有元素协调统一

#### 关键要素

- **详细场景描述**：包含所有视觉元素
- **时间/天气**：金色时段、黄昏、雨天等
- **相机规格**：镜头类型、焦距、角度、构图
- **艺术风格**：印象派、数字绘景、商业摄影等

## 3. Flux (Flux 1.1 Pro)

### 特点
- ⚠️ **可能需要更专业的提示词**：但不需要"魔法提示词"
- ✅ **风格化和想象力**：适合抽象和创意提示
- ✅ **迭代编辑能力强**：支持渐进式优化

### 提示词优化策略

#### 编辑指令优化

✅ **清晰的局部编辑指令**：
```
"只将椅子的颜色改为红色，保持房间其他部分不变"
```

✅ **渐进式细化**：
```
第一阶段：调整整体场景
第二阶段：添加细节
第三阶段：最终润色
```

✅ **保持一致性**：
```
"在所有帧中保持角色面部完全一致"
```

#### 提示词结构

虽然不需要"魔法提示词"，但结构化的提示词效果更好：

```
[主体描述] + [动作/姿态] + [环境/背景] + [光线] + [风格] + [技术参数]
```

#### 与 nano-banana 和 seedream-4 的区别

- **Flux** 更注重**风格化**和**创意表达**
- **nano-banana** 更注重**真实感**和**知识整合**
- **seedream-4** 更注重**电影级视觉效果**

## 4. 对比总结

| 特性 | nano-banana | seedream-4 | flux |
|------|-------------|------------|------|
| **需要"魔法提示词"** | ❌ 不需要 | ❌ 不需要 | ❌ 不需要 |
| **理解自然语言** | ✅ 优秀 | ✅ 良好 | ✅ 良好 |
| **提示词风格** | 描述性、具体 | 结构化、详细 | 专业、风格化 |
| **优势领域** | 真实感、文本渲染、知识整合 | 电影级视觉效果、艺术风格 | 创意表达、风格化 |
| **提示词长度** | 100-200 字 | 详细描述 | 中等长度 |
| **特殊能力** | 真实世界知识、多图理解 | 高分辨率、批量生成 | 迭代编辑、一致性 |

## 5. 通用最佳实践

### ✅ 推荐做法

1. **具体描述**：避免模糊词汇，使用具体细节
2. **结构化组织**：主体 → 动作 → 场景 → 光线 → 风格
3. **避免过度提示**：不要堆砌形容词，保持自然
4. **逐步优化**：从简单开始，逐步添加细节

### ❌ 避免做法

1. **避免陈词滥调**：
   - ❌ "4K, masterpiece, best quality, highly detailed"
   - ❌ "ultra realistic, 8k, trending on artstation"

2. **避免模糊描述**：
   - ❌ "加文字" → ✅ "用红色 serif 字体写'Hello'在标志中央"
   - ❌ "好看的光线" → ✅ "从左侧柔和漫射光照射"

3. **避免过度提示**：
   - ❌ 堆砌大量形容词
   - ✅ 保持自然、简洁的描述

  prompt: string, 
  model: 'nano-banana' | 'seedream-4' | 'flux-fast'

  switch (model) {

      // nano-banana 理解自然语言，只需确保描述具体
      return ensureDescriptive(prompt);
    
    case 'seedream-4':
      // seedream-4 需要结构化描述
      return structurePrompt(prompt);
    
    case 'flux-fast':
      // flux 需要专业术语和风格描述
      return addStyleTerms(prompt);
    
    default:
      return prompt;
  }
}

/**
 * 确保提示词是描述性的（nano-banana）
 */
function ensureDescriptive(prompt: string): string {
  // 移除常见的"魔法提示词"
  const magicWords = [
    '4K', 'masterpiece', 'best quality', 'highly detailed',

  ];
  
  let cleaned = prompt;
  for (const word of magicWords) {

}
