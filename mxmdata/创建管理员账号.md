# 创建 Admin 账号指南

## 概述

Admin 账号是拥有管理员权限的用户，`role` 字段为 `'admin'`。可以通过多种方式创建 admin 账号。

## 方式一：使用本地 TypeScript 脚本（推荐，最简单，不通过 Gateway）

**这是最推荐的方式**，脚本直接在本地运行，直接连接数据库，不通过 Gateway 接口。

### 快速使用

```bash
# 方式 1：使用 npm script（推荐）
cd mxmdata
pnpm create:admin

# 方式 2：直接运行脚本
cd mxmdata
tsx src/scripts/create-admin-user.ts

# 方式 3：自定义参数
cd mxmdata
tsx src/scripts/create-admin-user.ts myadmin admin@mycompany.com mypassword123
```

### 脚本说明

- **位置**：`mxmdata/src/scripts/create-admin-user.ts`
- **特点**：
  - ✅ **本地脚本**，直接在系统内部操作
  - ✅ **不通过 Gateway**，直接连接 Supabase 数据库
  - ✅ 使用 `RepositoryFactory`，与业务代码一致
  - ✅ 自动处理用户已存在的情况（更新为 admin）
  - ✅ 自动创建用户设置
  - ✅ 密码加密使用 bcrypt，与注册接口一致

### 工作原理

1. 加载环境变量（从 `mxmdata/.env` 或项目根目录 `.env`）
2. 初始化 `RepositoryFactory`（直接连接 Supabase，不通过 Gateway）
3. 检查用户是否已存在
4. 如果存在，更新角色为 `admin`
5. 如果不存在，创建新用户并设置角色为 `admin`
6. 自动创建用户设置

**重要**：此脚本是**本地脚本**，不依赖 Gateway，直接在本地运行，直接操作数据库。

## 方式四：使用 Node.js 脚本创建（已废弃，请使用方式一）

创建脚本 `mxmdata/create-admin-user.js`：

```javascript
const bcrypt = require('bcrypt');
const { createClient } = require('@supabase/supabase-js');

// 从环境变量读取配置
const supabaseUrl = process.env.SUPABASE_URL || 'http://localhost:8000';
const supabaseServiceKey = process.env.SUPABASE_SERVICE_KEY || 'your-service-key';

const supabase = createClient(supabaseUrl, supabaseServiceKey);

async function createAdminUser() {
  const username = process.argv[2] || 'admin';
  const email = process.argv[3] || 'admin@example.com';
  const password = process.argv[4] || 'admin123';

  console.log('🔐 创建 Admin 用户...');
  console.log(`   用户名: ${username}`);
  console.log(`   邮箱: ${email}`);

  // 生成密码哈希
  const passwordHash = await bcrypt.hash(password, 10);
  console.log('✅ 密码哈希已生成');

  // 创建用户
  const { data, error } = await supabase
    .from('users')
    .insert({
      username,
      email,
      password_hash: passwordHash,
      role: 'admin',
      status: 'active',
      level: 10,
      membership_type: 'premium',
    })
    .select()
    .single();

  if (error) {
    if (error.code === '23505') {
      console.log('⚠️  用户已存在，更新为 admin 角色...');
      const { data: updateData, error: updateError } = await supabase
        .from('users')
        .update({ role: 'admin' })
        .eq('username', username)
        .select()
        .single();

      if (updateError) {
        console.error('❌ 更新失败:', updateError);
        process.exit(1);
      }
      console.log('✅ Admin 角色已更新');
      console.log('📋 用户信息:', updateData);
    } else {
      console.error('❌ 创建失败:', error);
      process.exit(1);
    }
  } else {
    console.log('✅ Admin 用户创建成功');
    console.log('📋 用户信息:', data);
  }

  // 创建用户设置
  const { error: settingsError } = await supabase
    .from('user_settings')
    .upsert({
      user_id: data?.id || updateData?.id,
      theme: 'dark',
      language: 'zh',
      notifications_enabled: true,
    });

  if (settingsError && settingsError.code !== '23505') {
    console.warn('⚠️  创建用户设置失败:', settingsError);
  } else {
    console.log('✅ 用户设置已创建');
  }
}

createAdminUser().catch(console.error);
```

**使用方法**：

```bash
# 使用默认值（用户名：admin，邮箱：admin@example.com，密码：admin123）
node mxmdata/create-admin-user.js

# 自定义参数
node mxmdata/create-admin-user.js myadmin admin@mycompany.com mypassword
```

## 方式四：使用 TypeScript 脚本（推荐，类型安全）

创建脚本 `mxmdata/src/scripts/create-admin-user.ts`：

```typescript
import dotenv from 'dotenv';
import * as path from 'path';
import { RepositoryFactory } from '../src/factories/RepositoryFactory';
import { hashPassword } from '../../mxmauth/src/auth/password';

// 加载环境变量
const envPath = path.resolve(__dirname, '../../.env');
dotenv.config({ path: envPath });

async function createAdminUser() {
  const username = process.argv[2] || 'admin';
  const email = process.argv[3] || 'admin@example.com';
  const password = process.argv[4] || 'admin123';

  console.log('🔐 创建 Admin 用户...');
  console.log(`   用户名: ${username}`);
  console.log(`   邮箱: ${email}`);

  try {
    // 初始化 RepositoryFactory
    RepositoryFactory.init();

    const userRepo = RepositoryFactory.createUserRepository();

    // 检查用户是否已存在
    let user;
    try {
      user = await userRepo.findByUsername(username);
      if (user) {
        console.log('⚠️  用户已存在，更新为 admin 角色...');
        await userRepo.update(user.id, { role: 'admin' });
        console.log('✅ Admin 角色已更新');
        return;
      }
    } catch (error) {
      // 用户不存在，继续创建
    }

    // 生成密码哈希
    const passwordHash = await hashPassword(password);
    console.log('✅ 密码哈希已生成');

    // 创建用户
    user = await userRepo.create({
      username,
      email,
      password_hash: passwordHash,
      role: 'admin',
      status: 'active',
      level: 10,
      membership_type: 'premium',
    });

    console.log('✅ Admin 用户创建成功');
    console.log('📋 用户信息:', {
      id: user.id,
      username: user.username,
      email: user.email,
      role: user.role,
      status: user.status,
    });
  } catch (error: any) {
    console.error('❌ 创建失败:', error.message);
    process.exit(1);
  }
}

createAdminUser();
```

**使用方法**：

```bash
# 编译并运行
cd mxmdata
tsx src/scripts/create-admin-user.ts

# 或使用自定义参数
tsx src/scripts/create-admin-user.ts myadmin admin@mycompany.com mypassword
```

## Admin 权限说明

Admin 账号拥有以下权限：

1. **知识库管理**：
   - 可以创建公开的知识库
   - 可以管理所有用户的知识库

2. **系统管理**：
   - 可以查看系统配置信息
   - 可以管理用户任务

3. **其他管理功能**：
   - 根据各模块的 `adminMiddleware` 配置

## 安全建议

1. **强密码**：使用强密码（至少 12 位，包含大小写字母、数字、特殊字符）
2. **定期更换**：定期更换 admin 密码
3. **限制访问**：限制 admin 账号的登录 IP
4. **审计日志**：记录 admin 账号的所有操作
5. **多因素认证**：为 admin 账号启用多因素认证（如果支持）

## 故障排查

### 问题：创建后无法登录

**检查**：
1. 密码哈希是否正确
2. 用户状态是否为 `'active'`
3. 用户名/邮箱是否正确

### 问题：没有 admin 权限

**检查**：
1. `role` 字段是否为 `'admin'`（不是 `'Admin'` 或 `'ADMIN'`）
2. 中间件是否正确检查了角色

### 问题：用户已存在

**解决方案**：
```sql
-- 更新现有用户为 admin
UPDATE users 
SET role = 'admin' 
WHERE username = 'your-username';
```
