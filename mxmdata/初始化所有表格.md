# 使用 Supabase Dashboard 初始化数据库

如果本地没有安装 `psql`，可以使用 Supabase Dashboard 手动执行 SQL 文件。

## 步骤

### 1. 启用 pgvector 扩展
在 **SQL Editor** 中执行：
CREATE EXTENSION IF NOT EXISTS vector;

### 2. 执行 SQL 文件

在 **SQL Editor** 中，按以下顺序依次执行：

#### 步骤 1：基础配置
- 文件：`mxmdata/src/database/schemas/supabase-init.sql`
- 作用：创建必要的角色和权限

#### 步骤 2：用户管理
- 文件：`mxmdata/src/database/schemas/mxmauth.sql`
- 作用：创建 `users`、`user_settings`、`user_sessions` 表

#### 步骤 3：支付模块
- 文件：`mxmdata/src/database/schemas/mxmpay.sql`
- 作用：创建 `wallets`、`transactions`、`payment_methods` 表

#### 步骤 4：CGI 任务
- 文件：`mxmdata/src/database/schemas/mxmcgi.sql`
- 作用：创建 `cgi_tasks` 表

#### 步骤 5：通知模块
- 文件：`mxmdata/src/database/schemas/mxmnotify.sql`
- 作用：创建通知相关表

#### 步骤 6：提示词优化（需要 pgvector）
- 文件：`mxmdata/src/database/schemas/mxmprompt.sql`
- 作用：创建 `base_models`、`lora_models`、`prompt_templates`、`generation_cases` 表

#### 步骤 7：知识库（需要 pgvector）
- 文件：`mxmdata/src/database/schemas/knowledge_base.sql`
- 作用：创建 `knowledge_bases`、`knowledge_base_documents` 表

#### 步骤 8：Agent 模块
- 文件：`mxmdata/src/database/schemas/mxmagent_final_safe.sql`
- 作用：创建 Agent 和 Smartflow 相关表

## 执行方式

1. 打开每个 SQL 文件
2. 复制全部内容
3. 粘贴到 Supabase Dashboard 的 SQL Editor
4. 点击 **Run** 执行
5. 检查是否有错误
6. 继续下一个文件

## 验证

执行完成后，在 SQL Editor 中运行：

```sql
-- 检查所有表
SELECT table_name 
FROM information_schema.tables 
WHERE table_schema = 'public' 
ORDER BY table_name;

-- 检查扩展
SELECT * FROM pg_extension WHERE extname = 'vector';
```

自动化脚本执行
`mxmdata/init-all-tables.sh`
