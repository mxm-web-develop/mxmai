Graph API 完整参数参考

接口地址 

POST /api/v1/graph/:modelName

支持的模型：nano-banana, flux-fast, ideogram-v2a, flux-kontext-fast, recraft-crisp-upscale, seedream-4

请求头 

Content-Type: application/json
x-user-id: <userId>  # 必需：用户ID

查询参数

参数 类型 说明 示例
provider string 指定提供商：deerapi、ppio、replicate。如果不指定，使用默认提供商（从 .env 的 DEFAULT_PROVIDER 读取） ?provider=deerapi
storeToMinio boolean 是否存储结果到 MinIO（也可以通过请求体传递） ?storeToMinio=true

请求体参数

基础参数（所有模型通用）

参数 类型 必需 说明 示例
prompt string ✅ 生成提示词 "A cute baby sea otter"
negativePrompt string ❌ 负面提示词（不希望出现的内容） "blurry, low quality"

Nano-Banana 专用参数

参数 类型 必需 说明 可选值
aspect_ratio string ❌ 图片宽高比 "1:1", "3:2", "2:3", "3:4", "4:3", "4:5", "5:4", "9:16", "16:9", "21:9"
image_size string ❌ 图片清晰度/尺寸 "1K"（默认）, "2K", "4K"
image string ❌ 单张参考图片（用于图片编辑），支持 URL 或 Base64 data URI "https://example.com/image.jpg" 或 "data:image/jpeg;base64,..."
image_urls string[] ❌ 多张参考图片 URL 列表（用于多图理解和合成） ["https://example.com/img1.jpg", "https://example.com/img2.jpg"]
image_base64s string[] ❌ 多张参考图片 Base64 列表（用于多图理解和合成） ["base64string1", "base64string2"]

存储配置参数

参数 类型 必需 说明 默认值
storeToMinio boolean ❌ 是否将结果存储到 MinIO。false 时返回 Base64，true 时返回 MinIO URL false
storageConfig object ❌ MinIO 存储配置（仅在 storeToMinio=true 时生效） 见下方说明

storageConfig 对象

参数 类型 必需 说明 默认值
bucket string ❌ MinIO 存储桶名称 "user-media"（从环境变量 CGI_STORAGE_BUCKET 读取）
pathTemplate string ❌ 文件路径模板，支持变量：{userId}, {date}, {timestamp}, {randomId}, {index}, {ext}, {modelName} "graph/{userId}/{modelName}/{timestamp}"

请求示例

1. 基础文本生成图片（默认提供商，返回 Base64） 

POST /api/v1/graph/nano-banana
Headers:
  x-user-id: user123
Content-Type: application/json

{
  "prompt": "A cute baby sea otter",
  "aspect_ratio": "1:1",
  "image_size": "2K"
}

响应：

{
  "success": true,
  "model": "nano-banana",
  "data": {
    "taskId": "abc123def456",
    "status": "pending",
    "createdAt": "2025-01-17T10:30:00.000Z"
  }
}

2. 指定提供商（DeerAPI） 

POST /api/v1/graph/nano-banana?provider=deerapi
Headers:
  x-user-id: user123
Content-Type: application/json

{
  "prompt": "A cute baby sea otter",
  "aspect_ratio": "16:9",
  "image_size": "4K"
}

3. 指定提供商（PPIO） 

POST /api/v1/graph/nano-banana?provider=ppio
Headers:
  x-user-id: user123
Content-Type: application/json

{
  "prompt": "A cute baby sea otter",
  "aspect_ratio": "3:2",
  "image_size": "2K"
}

4. 指定提供商（Replicate） 

POST /api/v1/graph/nano-banana?provider=replicate
Headers:
  x-user-id: user123
Content-Type: application/json

{
  "prompt": "A cute baby sea otter",
  "aspect_ratio": "1:1"
}

注意： Replicate 的 nano-banana 不支持 image_size 参数，只支持 aspect_ratio。

5. 存储结果到 MinIO（返回 MinIO URL） 

POST /api/v1/graph/nano-banana?provider=deerapi
Headers:
  x-user-id: user123
Content-Type: application/json

{
  "prompt": "A cute baby sea otter",
  "aspect_ratio": "1:1",
  "image_size": "2K",
  "storeToMinio": true,
  "storageConfig": {
    "bucket": "user-media",
    "pathTemplate": "graph/{userId}/{modelName}/{timestamp}-{randomId}.{ext}"
  }
}

参数说明

aspect_ratio（宽高比）

值 说明 适用场景
1:1 正方形 头像、图标、社交媒体
3:2 横向 3:2 照片、风景
2:3 纵向 2:3 人像、竖屏照片
3:4 纵向 3:4 人像、竖屏照片
4:3 横向 4:3 传统照片比例
4:5 纵向 4:5 Instagram 竖屏
5:4 横向 5:4 传统照片比例
9:16 纵向 9:16 手机竖屏、短视频
16:9 横向 16:9 宽屏、视频、横幅
21:9 超宽屏 21:9 电影、超宽屏

image_size（清晰度）

值 说明 文件大小（估算） 适用场景
1K 标准清晰度（默认） ~500KB - 1MB 快速预览、缩略图
2K 高清 ~1MB - 3MB 一般用途、社交媒体
4K 超高清 ~3MB - 10MB 高质量输出、打印

注意：

  • DeerAPI 和 PPIO 支持 1K、2K、4K
  • Replicate 的 nano-banana 不支持 image_size 参数

provider（提供商）

提供商 说明 特点
deerapi DeerAPI（默认，如果 .env 中 DEFAULT_PROVIDER=deerapi） 同步返回，支持 Base64 和 URL 输入
ppio PPIO 支持 Base64 和 URL 输入
replicate Replicate 异步任务，不支持 image_size 参数

最佳实践

  1. 选择提供商：

    • 需要快速响应：使用 deerapi 或 ppio
    • 需要高质量：使用 replicate（但需要等待）

  2. 存储选择：

    • 临时预览：storeToMinio: false（返回 Base64）
    • 长期存储：storeToMinio: true（返回 MinIO URL）

  3. 清晰度选择：

    • 快速测试：image_size: "1K"
    • 一般用途：image_size: "2K"
    • 高质量输出：image_size: "4K"

  4. 图片输入格式：

    • 单张图片：使用 image 参数（URL 或 Base64）
    • 多张图片 URL：使用 image_urls 数组
    • 多张图片 Base64：使用 image_base64s 数组

  5. 轮询任务状态：

    • 建议每 1-2 秒查询一次任务状态
    • 任务完成后，从 result.mediaUrls 获取结果
