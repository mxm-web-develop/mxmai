# 视频生成接口文档

## 概述

视频生成接口提供文本转视频、图片转视频、视频转视频等功能，支持 Sora 2 系列模型和 Runway 模型。所有视频生成请求统一走异步任务系统，通过任务接口追踪生成进度和结果。

---

## 接口列表

### 1. 获取可用模型列表

获取所有可用的视频生成模型。

**接口信息**
- **方法**: `GET`
- **路径**: `/api/v1/video/models`

**请求示例**

```bash
curl -X GET http://localhost:3000/api/v1/video/models \
  -H "Authorization: Bearer <token>"
```

**响应示例**

```json
{
  "models": [
    {
      "name": "sora-2"
    },
    {
      "name": "sora-2-pro"
    },
    {
      "name": "sora-2-all"
    },
    {
      "name": "sora-2-pro-all"
    },
    {
      "name": "runway"
    }
  ]
}
```

---

### 2. 生成视频

根据指定的模型生成视频，所有请求均为异步任务模式。

**接口信息**
- **方法**: `POST`
- **路径**: `/api/v1/video/:modelName`
- **模式**: 异步任务

**路径参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| modelName | string | 是 | 模型名称，如 `sora-2`、`runway` |

**查询参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| provider | string | 否 | 指定 provider（如 `deer`），不指定则使用默认 provider |
| storeToMinio | boolean | 否 | 是否存储到 MinIO（默认 `false`，通过 query 参数传递时使用字符串 `'true'`） |

**请求体参数**

根据模型类型不同，参数有所差异：

#### Sora 2 系列模型参数（`sora-2`、`sora-2-pro`、`sora-2-all`、`sora-2-pro-all`）

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| prompt | string | 是 | 视频生成提示词 |
| seconds | string | 否 | 视频时长：`4`、`8`、`12` 秒 |
| size | string | 否 | 视频分辨率：`720x1280`、`1280x720`、`1024x1792`、`1792x1024` |
| input_reference | string | 否 | 参考图片（base64 或 URL），用于控制视频风格 |
| enableProgress | boolean | 否 | 是否启用进度监控（默认 `true`） |
| storeToMinio | boolean | 否 | 是否存储到 MinIO（默认 `false`） |
| storageConfig | object | 否 | 自定义存储配置（覆盖默认路径） |

#### Runway 模型参数（`runway`）

Runway 模型支持多种生成模式，根据提供的参数自动选择：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| prompt | string | 条件必填 | 视频生成提示词（图片转视频和文本转视频时必填） |
| promptImage | string | 条件必填 | 参考图片（base64 或 URL），用于图片转视频（与 `videoUri` 二选一必填） |
| videoUri | string | 条件必填 | 参考视频 URI，用于视频转视频（与 `promptImage` 二选一必填） |
| ratio | string | 否 | 视频宽高比，如 `16:9`、`9:16`、`1:1` 等 |
| duration | number | 否 | 视频时长（秒） |
| storeToMinio | boolean | 否 | 是否存储到 MinIO（默认 `false`） |
| storageConfig | object | 否 | 自定义存储配置（覆盖默认路径） |

**请求示例（Sora 2）**

```bash
curl -X POST http://localhost:3000/api/v1/video/sora-2 \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "A beautiful sunset over the ocean with waves gently crashing on the shore",
    "seconds": "8",
    "size": "1280x720",
    "input_reference": "data:image/jpeg;base64,/9j/4AAQSkZJRg...",
    "storeToMinio": true
  }'
```

**请求示例（Runway - 图片转视频）**

```bash
curl -X POST http://localhost:3000/api/v1/video/runway \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "A cat walking on the street",
    "promptImage": "data:image/jpeg;base64,/9j/4AAQSkZJRg...",
    "ratio": "16:9",
    "duration": 5,
    "storeToMinio": true
  }'
```

**请求示例（Runway - 视频转视频）**

```bash
curl -X POST http://localhost:3000/api/v1/video/runway \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "videoUri": "https://example.com/video.mp4",
    "ratio": "16:9",
    "storeToMinio": true
  }'
```

**响应示例**

```json
{
  "success": true,
  "model": "sora-2",
  "data": {
    "taskId": "task_xxx",
    "status": "pending",
    "createdAt": "2024-01-01T00:00:00Z"
  }
}
```

**任务结果查询**

通过 `GET /api/v1/cgi-tasks/:taskId` 查询任务状态和结果。

**结果格式**

```json
{
  "success": true,
  "data": {
    "id": "task_xxx",
    "type": "video",
    "status": "completed",
    "result": {
      "mediaUrls": ["https://minio.example.com/user-123/video/1234567890-abc123.mp4"],
      "storageInfo": {
        "keys": ["user-123/video/1234567890-abc123.mp4"],
        "bucket": "user-media",
        "urls": ["https://minio.example.com/..."]
      },
      "metadata": {
        "duration": 8,
        "resolution": "1280x720",
        "format": "mp4"
      }
    }
  }
}
```

## 模型说明

### Sora 2 系列

- **sora-2**: 标准 Sora 2 模型，文本转视频
- **sora-2-pro**: 专业版 Sora 2 模型，更高质量
- **sora-2-all**: 逆向异步 Sora 2（自研接口）
- **sora-2-pro-all**: 逆向异步 Sora 2 Pro（自研接口）

**特性**：
- 支持文本转视频
- 支持参考图片（`input_reference`）控制视频风格
- 支持多种分辨率和时长
- 自动处理参考图片尺寸，确保与视频分辨率匹配

### Runway

- **runway**: 统一视频生成接口，自动选择生成模式

**支持模式**：
- **图片转视频**：提供 `promptImage` 和 `prompt`
- **文本转视频**：仅提供 `prompt`（部分场景）
- **视频转视频**：提供 `videoUri`（`prompt` 可选）

---

## 使用说明

### 1. 参考图片处理

对于 Sora 2 系列模型，如果提供了 `input_reference` 和 `size`，系统会自动：
- 检查图片尺寸是否与视频分辨率匹配
- 自动调整图片尺寸以匹配视频分辨率
- 压缩图片以优化传输

### 2. 存储到 MinIO

设置 `storeToMinio: true` 时，生成的视频会自动存储到 MinIO，存储路径格式：
```
{userId}/video/{timestamp}-{randomId}.{ext}
```

### 3. Provider 选择

- 可通过 `provider` 查询参数指定 provider
- 不指定时，系统自动选择支持该模型的 provider
- 当前主要支持 `deer` provider

### 4. 进度监控

Sora 2 系列模型支持进度监控（`enableProgress: true`），可通过任务接口实时查看生成进度。

## 完整接口路径映射

```
/api/v1/video/models          → /video/models
/api/v1/video/:modelName      → /video/:modelName
```

---

## 注意事项

1. **异步任务**：所有视频生成均为异步任务，需要通过任务接口查询结果
2. **参考图片**：Sora 2 模型的参考图片会自动调整尺寸，确保与视频分辨率匹配
3. **Runway 参数**：Runway 模型至少需要提供 `promptImage` 或 `videoUri` 之一
4. **权限控制**：只能访问自己创建的任务和视频文件
5. **存储路径**：可通过 `storageConfig` 自定义存储路径，否则使用默认路径
6. **视频时长**：不同模型支持的时长不同，请参考具体模型文档
