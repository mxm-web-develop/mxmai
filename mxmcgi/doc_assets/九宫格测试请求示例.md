# 九宫格模式 Postman 测试请求示例

## 基础配置

**Base URL**: `http://localhost:3000`（Gateway地址，不是直接访问mxmcgi）

**必需 Header**:
```
Content-Type: application/json
Authorization: Bearer <your-jwt-token>
```

**重要说明**:
- 所有请求通过 Gateway 访问
- Gateway 会自动从 JWT Token 中提取 userId，无需手动传递 `x-user-id`
- Token 从登录接口获取（`POST /api/v1/account/login`）

## 验证请求

### 查询任务列表（验证父任务已隐藏）

**请求URL**: `GET /api/v1/cgi-tasks?type=graph&limit=20`

**Header**:
```
Authorization: Bearer <your-jwt-token>
```

**预期结果**: 
- 列表中不包含 `graph-grid9-parent` 类型的任务
- 只显示 9 个 `graph` 类型的子任务

---

### 查询单个子任务（验证metadata）

**请求URL**: `GET /api/v1/cgi-tasks/{taskId}`

**Header**:
```
Authorization: Bearer <your-jwt-token>
```

**参数**: 将 `{taskId}` 替换为子任务的ID

**预期结果**:
```json
{
  "success": true,
  "data": {
    "id": "child-task-id",
    "type": "graph",
    "status": "completed",
    "result": {
      "mediaUrls": ["minio-url-1"],
      "metadata": {
        "grid9": true,
        "grid9Type": "child",
        "parentTaskId": "parent-task-id",
        "grid9Index": 0,
        "grid9Position": { "row": 1, "col": 1 },
        "graphType": "photograph",
        "type": "portrait"
      }
    }
  }
}
```

---

### 查询父任务（验证完整大图）

**请求URL**: `GET /api/v1/cgi-tasks/{parentTaskId}`

**Header**:
```
Authorization: Bearer <your-jwt-token>
```

**参数**: 将 `{parentTaskId}` 替换为父任务的ID（从子任务的metadata.parentTaskId获取）

**预期结果**:
```json
{
  "success": true,
  "data": {
    "id": "parent-task-id",
    "type": "graph-grid9-parent",
    "status": "completed",
    "result": {
      "mediaUrls": ["minio-url-grid9-image"],
      "metadata": {
        "grid9": true,
        "grid9Type": "parent",
        "childTaskIds": ["child-1", "child-2", ..., "child-9"],
        "originalGrid9Image": "minio-url-grid9-image"
      }
    }
  }
}
```

## cURL 命令示例

### 创建九宫格任务

```bash
curl -X POST http://localhost:3000/api/v1/cgi/graph/photograph \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <your-jwt-token>" \
  -d '{
    "type": "portrait",
    "prompt": "一位优雅的女性，在现代化的室内环境中",
    "style": "modern",
    "tone": "warm",
    "environment": "indoor",
    "lighting": "soft",
    "quality": "high",
    "grid9": true,
    "grid9Mode": "combination",
    "storeToMinio": true
  }'
```

### 查询任务列表

```bash
curl -X GET "http://localhost:3000/api/v1/cgi-tasks?type=graph&limit=20" \
  -H "Authorization: Bearer <your-jwt-token>"
```

### 查询单个任务

```bash
curl -X GET "http://localhost:3000/api/v1/cgi-tasks/{taskId}" \
  -H "Authorization: Bearer <your-jwt-token>"
```

## 测试流程

1. **创建九宫格任务**
   - 使用上述任一请求示例创建任务
   - 记录返回的 `taskId`

2. **等待任务完成**
   - 任务状态会从 `pending` → `queued` → `processing` → `completed`
   - 可以通过轮询任务状态或使用 SSE 监听任务进度

3. **验证任务转换**
   - 查询任务列表，应该看到 9 个子任务
   - 验证父任务不在列表中显示

4. **验证子任务metadata**
   - 查询任意一个子任务
   - 验证 metadata 中包含 `parentTaskId`、`grid9Index` 等信息

5. **验证父任务**
   - 通过子任务的 `parentTaskId` 查询父任务
   - 验证父任务包含完整大图和 `childTaskIds`

---

## 注意事项

1. **Token认证**: 所有请求都需要在 Header 中提供 `Authorization: Bearer <token>`
2. **Gateway自动处理**: Gateway 会自动从 token 中提取 userId，无需手动传递 `x-user-id`
2. **存储配置**: 如果 `storeToMinio: true`，需要确保 MinIO 配置正确
3. **任务状态**: 九宫格任务处理时间较长，需要等待图片生成、切割、上传等步骤完成
4. **错误处理**: 如果任务失败，检查服务器日志中的 `[GraphTask]` 相关错误信息
