## 二、数据格式要求

### 支持的文件格式

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| 纯文本 | `.txt` | 最简单，直接上传 |
| Markdown | `.md` | 推荐，支持格式化 |
| PDF | `.pdf` | 需要安装 pdf-parse |

### 内容格式建议

**推荐结构**：
```markdown
# 标题（清晰描述主题）

## 概述
简要介绍...

## 详细内容
1. 要点一
2. 要点二

## 示例
具体示例...

## 注意事项
重要提醒...
```

### 内容要求

1. **准确性**：内容必须准确、可靠
2. **相关性**：与 Agent 领域相关
3. **完整性**：内容完整，避免碎片化
4. **时效性**：优先使用最新信息

---

## 三、整理流程

### 步骤 1：收集数据

从上述来源收集相关文档，保存为 `.md` 或 `.txt` 格式。

### 步骤 2：清理和格式化

- 移除无关内容
- 统一格式
- 添加清晰的标题层级

### 步骤 3：上传到知识库

```bash
curl -X POST http://localhost:3000/api/v1/knowledge/bases/agent-image/upload \
  -H "Authorization: Bearer <token>" \
  -F "file=@document.md" \
  -F "tags=[\"标签1\", \"标签2\"]"
```

### 步骤 4：验证效果

搜索测试，确保能检索到相关内容。

## 五、最佳实践

1. **分主题整理**：按主题分类，便于管理
2. **添加标签**：使用标签便于检索
3. **定期更新**：保持内容最新
4. **质量控制**：确保内容准确可靠

## 六、批量导入

如果有多个文档，可以批量上传：

```bash
for file in *.md; do
  curl -X POST http://localhost:3000/api/v1/knowledge/bases/agent-image/upload \
    -H "Authorization: Bearer <token>" \
    -F "file=@${file}"
done
```
