# 系统知识库数据收集策略分析

## 一、当前系统架构分析

### 1.1 召回机制
- **双查询策略**：每个类型使用2个查询，每个查询最多召回3条
- **相似度阈值**：0.6（较低阈值以提高召回率）
- **最大保留数**：10条（去重后）
- **搜索方式**：Hybrid（向量搜索 + 关键词搜索）

### 1.2 查询构建逻辑

#### Portrait（人像）示例：
- **查询1**：`style + tone + lighting + prompt` → 构图/光线/风格/摄影师
- **查询2**：`prompt + environment + pose + makeup` → 背景/环境/姿势/妆容

#### Landscape（风景）示例：
- **查询1**：`timeOfDay + weather + prompt` → 时间/天气/场景
- **查询2**：`season + composition + prompt` → 季节/构图/场景

### 1.3 知识库结构
- **15个独立知识库**：每个子类型一个（如 `graph-photograph-portrait`）
- **双语支持**：需要中英文内容
- **私密知识库**：仅系统使用，用户不可见

## 二、数据收集策略

### 2.1 核心原则

#### 1. **参数组合覆盖**
每个知识库需要覆盖该类型的所有参数组合，确保任意参数组合都能召回相关内容。

#### 2. **查询词匹配**
文档内容需要包含用户可能输入的查询词（参数值、专业术语、同义词）。

#### 3. **语义丰富度**
每个文档应该包含：
- 核心概念的专业描述
- 参数组合的实际应用场景
- 技术细节和最佳实践
- 风格参考和案例说明

#### 4. **文档粒度**
- **单文档长度**：200-800字（适合chunk切分）
- **文档数量**：每个知识库至少50-100篇（最低要求）
- **理想数量**：每个知识库200-500篇（最佳效果）

### 2.2 数据收集维度

#### 维度1：参数组合覆盖
为每个参数组合创建专门的文档：

**Portrait 示例**：
- `现代风格 + 暖色调 + 柔光 + 室内环境 + 站立姿势 + 自然妆容`
- `复古风格 + 冷色调 + 硬光 + 室外环境 + 坐姿 + 精致妆容`
- ...（覆盖所有常见组合）

**Landscape 示例**：
- `清晨 + 晴天 + 春季 + 三分法构图`
- `黄昏 + 阴天 + 秋季 + 引导线构图`
- ...（覆盖所有常见组合）

#### 维度2：专业领域知识
- **技术知识**：构图原理、光线理论、色彩搭配
- **风格指南**：不同风格的特征和实现方法
- **案例研究**：优秀作品的分析和拆解
- **最佳实践**：行业标准和专业建议

#### 维度3：场景化内容
- **具体场景**：室内人像、室外风景、商业拍摄等
- **应用场景**：杂志封面、产品宣传、艺术创作等
- **特殊需求**：逆光拍摄、夜景拍摄、特殊天气等

#### 维度4：双语内容
- **中文文档**：面向中文用户查询
- **英文文档**：面向英文用户查询
- **双语文档**：同时包含中英文关键词

## 三、最低数据量要求

### 3.1 理论计算

#### 参数组合数量（Portrait为例）：
- style: 6个选项
- tone: 5个选项
- environment: 5个选项
- makeup: 5个选项
- pose: 6个选项
- lighting: 6个选项

**理论组合数**：6 × 5 × 5 × 5 × 6 × 6 = **27,000种组合**

**实际常用组合**：约 **200-500种**（根据用户使用频率）

#### 召回成功率计算：
- **相似度阈值0.6**：需要文档与查询的语义相似度 ≥ 0.6
- **每个查询召回3条**：需要至少有3篇相关文档
- **去重后保留10条**：需要至少有10篇不同主题的文档

### 3.3 数据质量要求

#### 1. **内容质量**
- ✅ 专业术语准确
- ✅ 技术描述详细
- ✅ 案例真实可信
- ✅ 风格特征明确

#### 2. **关键词覆盖**
- ✅ 包含所有参数选项值（如"现代"、"暖色调"、"柔光"）
- ✅ 包含专业术语（如"三分法"、"黄金分割"、"轮廓光"）
- ✅ 包含同义词和变体（如"室内"、"室内环境"、"室内拍摄"）

#### 3. **语义多样性**
- ✅ 不同角度的描述（技术角度、艺术角度、实用角度）
- ✅ 不同层次的深度（基础概念、进阶技巧、高级应用）
- ✅ 不同场景的应用（商业、艺术、纪实等）

## 四、数据收集方法

### 4.1 数据来源

#### 1. **专业摄影/设计教程**
- 摄影教程网站
- 设计类博客
- 专业书籍（需授权）

#### 2. **案例分析和作品拆解**
- 优秀作品的技术分析
- 摄影师/设计师的创作思路
- 行业奖项作品解析

#### 3. **技术文档和规范**
- 行业标准文档
- 设备使用指南
- 软件操作手册

#### 4. **用户生成内容（UGC）**
- 专业用户的创作经验
- 社区讨论和问答
- 实际应用案例

### 4.2 数据组织方式

#### 文档结构建议：
```
【标题】清晰描述文档主题（包含关键词）
【内容】200-800字的专业描述
  - 核心概念
  - 技术细节
  - 应用场景
  - 最佳实践
【标签】参数值、风格、技术点等
```

#### 示例文档（Portrait）：
```
标题：现代风格暖色调室内人像拍摄技巧

内容：
现代风格人像摄影强调简洁、时尚的视觉呈现。在室内环境中，使用柔光可以营造温暖、舒适的氛围。暖色调能够增强画面的情感表达，使人物看起来更加亲切自然。

构图方面，建议使用三分法或黄金分割原则，将人物主体放置在画面的关键位置。室内环境通常背景较为简洁，可以通过大光圈镜头实现背景虚化，突出人物主体。

光线设计是室内人像的关键。柔光可以通过使用柔光箱或反光板实现，避免硬光造成的强烈阴影。主光通常从45度角照射，辅光用于填充阴影，营造立体感。

色彩搭配方面，暖色调可以通过调整白平衡或后期调色实现。建议使用色温在3000-4000K的光源，或通过后期调整色温滑块，使画面呈现温暖的色调。

【标签】现代、暖色调、室内、柔光、人像、构图、光线
```

### 4.3 数据收集优先级

#### 第一阶段（最低要求 - 500篇）：
1. **核心参数组合**：覆盖最常用的20-30种参数组合
2. **基础技术知识**：构图、光线、色彩等基础概念
3. **风格指南**：每种风格的基本特征

#### 第二阶段（推荐要求 - 1,650篇）：
1. **扩展参数组合**：覆盖常用组合的80%
2. **进阶技术知识**：高级技巧和最佳实践
3. **场景化内容**：不同应用场景的专门指导
4. **案例研究**：优秀作品的分析

#### 第三阶段（理想要求 - 3,450篇）：
1. **全面参数覆盖**：覆盖所有可能的参数组合
2. **深度技术内容**：专业级的技术细节
3. **丰富案例库**：大量真实案例和参考
4. **双语内容**：完整的中英文双语支持

## 五、效果提升策略

### 5.1 召回率提升

#### 1. **关键词密度**
- 在文档中多次提及参数值（如"现代风格"出现3-5次）
- 使用同义词和变体（如"现代"、"现代感"、"现代风格"）

#### 2. **语义相关性**
- 描述相关概念（如"现代风格"文档中提及"简洁"、"时尚"、"前卫"）
- 包含技术细节（如"柔光"文档中提及"柔光箱"、"反光板"、"散射"）

#### 3. **文档多样性**
- 不同角度的文档（技术角度、艺术角度、实用角度）
- 不同深度的文档（基础、进阶、高级）

### 5.2 召回质量提升

#### 1. **文档质量**
- 专业术语准确
- 技术描述详细
- 案例真实可信

#### 2. **内容结构**
- 清晰的段落结构
- 逻辑清晰的论述
- 重点信息突出

#### 3. **更新维护**
- 定期更新过时内容
- 补充新的技术和方法
- 根据用户反馈优化
