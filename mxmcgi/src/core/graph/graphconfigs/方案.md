用户请求 (POST /photograph)
  ↓
路由层验证参数
  ↓
创建任务 (type: 'graph')
  ↓
任务执行器分发
  ↓
Graph 任务处理 (graph-task.ts)
  ├─ 4.1 获取任务
  ├─ 4.2 更新状态: pending → queued → processing
  ├─ 4.3 解析参数
  └─ 4.4 调用 generateGraph()
      ↓
      核心服务 (graph-service.ts)
      ├─ 阶段5: generateGraphPrompt()
      │   ├─ 提取业务参数
      │   ├─ 知识库召回
      │   │   ├─ 查询1: style + tone + lighting + prompt
      │   │   ├─ 查询2: prompt + environment + pose + makeup
      │   │   └─ Fallback: generateDefaultPortraitKnowledge()
      │   ├─ 检测输出语言
      │   ├─ 构建结构化用户需求
      │   ├─ 构建提示词生成请求
      │   └─ 调用 LLM (gemini-3-pro)
      │       ↓
      │   生成最终提示词
      │       ↓
      └─ 阶段6: generateGraphImage()
          ├─ 选择模型 (nano-banana / seedream-4)
          ├─ 准备参数 (prompt, aspect_ratio, referenceImage)
          └─ 调用图片生成模型
              ↓
          生成图片 (Base64 URLs)
              ↓
      返回结果 { prompt, image_urls, modelName }
          ↓
  ├─ 4.5 更新 metadata (使用生成的 prompt)
  ├─ 4.6 处理 MinIO 存储 (使用生成的图片)
  └─ 4.7 保存任务结果
      ↓
返回给用户 (通过任务查询接口)
