# GraphConfigs 文件使用情况检查

## 文件列表

### 根目录文件
1. **`index.ts`** ✅ **已使用**
   - 被 `graph-service.ts` 导入：`import { getGraphRulesForType, getGraphParamsForType } from './graphconfigs'`
   - 作用：提供配置映射和获取函数

2. **`photograph.ts`** ✅ **已使用**
   - 被 `index.ts` 导入：`import { photographConfig, type PhotographTypeConfig } from './photograph'`
   - 作用：定义 photograph 类型的配置（rules、参数列表、类型选项等）

3. **`design.ts`** ✅ **已使用**
   - 被 `index.ts` 导入：`import { designConfig, type DesignTypeConfig } from './design'`
   - 作用：定义 design 类型的配置

4. **`painting.ts`** ✅ **已使用**
   - 被 `index.ts` 导入：`import { paintingConfig, type PaintingTypeConfig } from './painting'`
   - 作用：定义 painting 类型的配置

5. **`方案.md`** 📄 **文档文件**
   - 作用：文档说明，不需要检查使用情况

### photograph 子目录文件
6. **`photograph/index.ts`** ❌ **未使用**
   - 定义了 `photographBasicConfig`，但没有任何地方导入或使用
   - 内容与 `photograph.ts` 中的通用 rules 有重复
   - **建议：可以删除**

7. **`photograph/portrait.ts`** ✅ **已使用**
   - 被 `graph-service.ts` 使用：`require('./graphconfigs/photograph/portrait')`
   - 被导入：`import { generateDefaultPortraitKnowledge } from './graphconfigs/photograph/portrait'`
   - 作用：提供 portrait 类型的详细配置和辅助函数

8. **`photograph/formOptions.ts`** ✅ **已使用**
   - 被 `routes/graph.ts` 导入：`import { getFormOptions } from '../core/graph/graphconfigs/photograph/formOptions'`
   - 作用：提供表单选项配置（中英文版本）

## 重复内容检查

### 发现重复
- **`photograph.ts`** 和 **`photograph/index.ts`** 都定义了通用的摄影 rules
  - `photograph.ts` 中的 `rules` 字段（第109-123行）
  - `photograph/index.ts` 中的 `photographBasicConfig.rules`（第9-22行）
  - 内容相似但不完全相同，`photograph/index.ts` 的版本更详细

## 建议

1. **删除未使用的文件**：
   - `photograph/index.ts` - 未被任何地方使用，且与 `photograph.ts` 有重复

2. **保留的文件**：
   - 所有其他文件都有明确的用途，应该保留
