## 二、数据格式要求

### 支持格式

| 格式 | 扩展名 | 推荐度 | 说明 |
|------|--------|--------|------|
| Markdown | `.md` | ⭐⭐⭐⭐⭐ | 推荐，支持格式化 |
| 纯文本 | `.txt` | ⭐⭐⭐⭐ | 简单直接 |
| PDF | `.pdf` | ⭐⭐⭐ | 需要解析库 |

### 内容结构要求

**理想结构**：
```markdown
# 主标题（清晰描述主题）

## 概述
简要介绍主题和用途

## 详细内容
分点说明，使用列表或段落

## 示例
提供具体示例

## 注意事项
重要提醒和限制
```

### 内容质量要求

1. **准确性**：内容必须准确、可靠
2. **相关性**：与 Agent 领域高度相关
3. **完整性**：内容完整，避免碎片化
4. **时效性**：优先使用最新信息
5. **结构化**：清晰的标题和段落

## 四、数据获取工具

### 1. 网页转 Markdown

**工具**：
- `pandoc`：`pandoc webpage.html -o output.md`
- 浏览器插件：Markdown Downloader
- 在线工具：各种网页转 Markdown 工具

### 2. PDF 转文本

**工具**：
- `pdf-parse`（Node.js 库）
- `pdftotext`（命令行工具）
- 在线 PDF 转换工具

### 3. 批量处理

**脚本示例**：
```bash
# 批量转换 HTML 到 Markdown
for file in *.html; do
  pandoc "$file" -o "${file%.html}.md"
done
```

## 五、数据预处理

### 清理步骤

1. **移除无关内容**：广告、导航、页脚等
2. **统一格式**：统一标题层级、列表格式
3. **添加元数据**：标题、标签、来源
4. **分块处理**：长文档分段（500-2000 字）

### 质量检查

- [ ] 内容准确性
- [ ] 格式一致性
- [ ] 标题清晰
- [ ] 段落完整
- [ ] 无重复内容

## 六、上传建议

### 单个文档

```bash
curl -X POST http://localhost:3000/api/v1/knowledge/bases/agent-image/upload \
  -H "Authorization: Bearer <token>" \
  -F "file=@document.md" \
  -F "tags=[\"摄影\", \"技巧\"]" \
  -F "metadata={\"source\": \"专业教程\", \"date\": \"2024-01-01\"}"
```

### 批量上传

```bash
for file in docs/*.md; do
  curl -X POST http://localhost:3000/api/v1/knowledge/bases/agent-image/upload \
    -H "Authorization: Bearer <token>" \
    -F "file=@${file}"
done
```
