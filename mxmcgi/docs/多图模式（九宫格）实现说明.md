# Graph 多图 / 宫格输出（当前行为说明）

## 概述

**Graph 图片任务不再**使用父子切图任务链路。`output_grid` 为 `2x2` 及以上时：一次 contact sheet 生图 → 服务端裁格 → `metadata.gridCells` 供选片；格位差异由 **Grid Prompt Plan**（脚本库 + 文案门禁）+ `text/format` 保证，详见 `GRAPH_BUSINESS_CONFIG_AND_SMARTFLOW.md`。

多格、合成一图、画幅等需求由 **DB 任务定义 + `formSchema` + `promptTextTaskKey`（text/format）** 在模板与参数层描述，由模型单次生成；列表与恢复逻辑**不**再针对「grid9 父任务」做特殊过滤或超时分支。

## 相关代码

- 任务执行与落库：`mxmcgi/src/core/graph/graph-task.ts`
- 提示词与生图：`mxmcgi/src/core/graph/graph-service.ts`
- CGI 任务列表：`mxmdata/src/adapters/supabase/SupabaseCGITaskRepository.ts`（无 grid9 父任务过滤）
- 任务超时恢复：`mxmcgi/src/task/task-recovery.ts`（无 grid9 专用分支）

## 与旧版的区别（便于迁移）

- 已移除：`graph-grid-layout.ts`、`grid9-splitter`、本地 `isGrid` 判断、gpt-image 仅因宫格而改 `parameters.size` 的分支、父/子 graph 任务链路。
- 历史库里若仍有 `grid9Type: 'parent'` 等记录，列表中会**正常展示**（不再隐藏）。
