# 应用多语言（I18N）

产品层统一四种语言，短码与 i18next / DB / `x-user-lang` / Agent `locale` 对齐。

## 语言码

| 产品码 (`AppLocale`) | 含义 | BCP-47（Intl / antd / html） |
|---------------------|------|------------------------------|
| `zh` | 简体中文 | `zh-CN` |
| `zh-TW` | 繁体中文 | `zh-TW` |
| `en` | 英语 | `en-US` |
| `ja` | 日语 | `ja-JP` |

共享实现：`@mxmai/mxmdata` → `normalizeAppLocale` / `pickLocalizedString` / `toBcp47` / `resolveAppLocaleByCountry`。

## 回退链

缺文案时按序取下一个非空值：

- `zh-TW` → `zh` → `en`
- `ja` → `en` → `zh`
- `en` → `en` → `zh`
- `zh` → `zh` → `en`

## 请求与偏好

| 来源 | 说明 |
|------|------|
| Web UI | i18next `lng`；localStorage `mxm-lang` |
| `x-user-lang` | Web API 客户端注入当前 UI 语言；VF / 生成内容默认跟此走 |
| `user_settings.language` | 服务端用户偏好（`AppLocale`） |
| `Accept-Language` | 邮件等无登录场景；用 `normalizeAppLocaleFromAcceptLanguage` |
| Agent `locale` | 会话级回复语言 |

IP 推断（无手动偏好）：`CN`→`zh`；`TW`/`HK`/`MO`→`zh-TW`；`JP`→`ja`；其余→`en`。

## 业务元数据

- 默认中文：`extra.display.taskLabel` / `subtypeLabel` / `description`
- 多语 map：`taskLabelI18n` / `subtypeLabelI18n` / `descriptionI18n` / `form_options_i18n` / `output_format_i18n`
- 键为 `zh` | `zh-TW` | `en` | `ja`；缺键运行时回退，不报错
- Admin「基础配置」可编辑显示名与业务描述（四语）；创建任务交互卡副文案读 `description` / `descriptionI18n`
- form-config API **透传**完整 map，由客户端 `pickDisplayLocalizedString`（有 primary）或 `pickLocalizedString` 解析

详见 `.cursor/skills/mxmai_business_naming/SKILL.md`。

## 范围说明

- **第一期**：Web C 端 UI、Admin 业务配置四语编辑、后端内容语言（Agent / 邮件 / VF / Writing）
- **不在第一期**：Admin 界面本地化、Mobile / H5、Smartflow 名称 i18n
