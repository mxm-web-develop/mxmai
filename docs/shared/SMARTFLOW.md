Smartflow实现具体细节：

节点包括开始，结束， 业务， 工具， 条件判断， varible, 循环。

开始节点，所有smartflow都有，用于开始一个smartflow, 设计并接收用户的传参

业务节点，可以选择mxmcgi里面所有已经创建的业务（就是我们web业务列表中的内容）

工具节点， 目前内置brave搜索，爬虫搜索，embedding，node.js代码执行器，python代码执行器

varible节点，可以将前面节点保存的输出进行聚合或抽离，然后保存成一个新输出

条件判断节点，if/else， 注意可以有多个else,

循环	，Iteration（迭代）：像 for item in list，处理数组里的每个元素，每一项通常互不影响。适合批量摘要、批量分类、批量改写、批量检索，Loop（循环）：像 while 条件成立，每一轮都会拿上一轮的输出继续推进。适合优化、修正、递归压缩、连续搜索、反复判断。

整个smartflow中用户可以通过开始节点start传入要用的参数，后面的所有节点都可以使用用户传入的参数，除此之外，每个节点的输出按照{节点名}+output来保存可以支持多种格式string,object等，后面的节点可以使用前面已经执行完的节点的输出作为参数。 这里有很多情况前面的节点输出striing是最简单的，但是前面的节点也有可能输出array,object,用户可以直接使用，或者用varible节点来聚合/抽离自己想要保存的数据结构。

Smartflow要有测试功能，运行功能，测试跑的时候每一步要有完整打印，运行跑的时候要有基础打印。
