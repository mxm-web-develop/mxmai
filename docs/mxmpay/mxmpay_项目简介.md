## 项目简介

mxmpay 是一个基于 Express 和 TypeScript 构建的现代化支付服务后端。它旨在为应用程序提供一个统一、可扩展的支付处理层，通过集成多种支付渠道（包括加密货币、微信/支付宝、PayPal、银行卡等），将复杂的支付逻辑抽象为简洁的 API，从而帮助开发者快速、安全地实现收款功能，并专注于核心业务开发。

### 核心特性
*   **多支付渠道集成**：支持加密货币、微信支付、支付宝、PayPal、银行卡、Apple IAP 以及代金券等多种支付方式，通过统一的接口进行调用。
*   **模块化网关设计**：采用工厂模式与接口抽象，支付渠道以独立的网关（Gateway）形式实现，易于扩展和维护新的支付提供商。
*   **区块链支付监听**：集成 Alchemy、Infura 等服务，提供可靠的区块链交易监听能力，自动化处理加密货币支付的回调与确认。
*   **定时任务调度**：利用 `node-cron` 实现后台任务，例如自动处理支付订单的过期逻辑，保障系统状态的时效性。
*   **内置二维码生成**：集成 `qrcode` 库，为需要扫码支付的渠道（如微信、支付宝、加密货币）动态生成支付二维码。
*   **输入验证与安全性**：使用 `express-validator` 对 API 请求进行严格的输入校验，并支持 CORS 配置，提升接口安全性。
*   **配置与环境管理**：通过 `dotenv` 管理环境变量，并设有独立的配置模块，使部署和不同环境的切换更为清晰。
*   **API 文档支持**：项目包含 Swagger 配置，便于生成和查看交互式 API 文档，提升开发与协作效率。

### 适用场景
*   **SaaS 平台或在线服务**：需要为用户提供订阅付费、一次性购买等多样化支付选项。
*   **电商与数字商品销售**：销售实体商品、虚拟物品或数字内容，并支持全球主流的支付方式。
*   **区块链相关应用**：需要接收 ETH 或其他 ERC-20 代币作为支付手段的 DApp、NFT 市场或链游项目。
*   **内部工具与微服务**：作为大型微服务架构中的独立支付处理服务，为其他业务服务提供支付能力。
