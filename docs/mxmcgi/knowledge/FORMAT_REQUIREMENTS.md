# 知识库数据格式要求

## 一、文件格式

### 支持格式

| 格式 | 扩展名 | 推荐度 | 说明 |
|------|--------|--------|------|
| **Markdown** | `.md` | ⭐⭐⭐⭐⭐ | 推荐，支持格式化 |
| **纯文本** | `.txt` | ⭐⭐⭐⭐ | 简单直接 |
| **PDF** | `.pdf` | ⭐⭐⭐ | 需要安装 pdf-parse |

### 文件大小

- **单个文件**：建议 < 10MB
- **单段内容**：建议 500-2000 字
- **总知识库**：建议 < 500MB

---

## 二、内容格式

### Markdown 格式（推荐）

```markdown
# 主标题（清晰描述主题）

## 概述
简要介绍主题和用途...

## 详细内容

### 子标题 1
- 要点一
- 要点二

### 子标题 2
1. 步骤一
2. 步骤二

## 示例

```代码示例
具体示例代码
```

## 注意事项
- 重要提醒
- 限制说明
```

### 纯文本格式

```
主标题

概述
简要介绍...

详细内容
要点一
要点二

示例
具体示例...

注意事项
重要提醒...
```

---

## 三、内容结构要求

### 必需元素

1. **清晰标题**：每个文档有明确的主题
2. **概述部分**：简要介绍内容
3. **详细内容**：分点说明
4. **示例**：提供具体示例（如有）

### 推荐结构

```
# 标题

## 概述
...

## 详细内容
...

## 示例
...

## 注意事项
...
```

---

## 四、内容质量要求

### 1. 准确性
- ✅ 内容准确、可靠
- ✅ 来源可信
- ❌ 避免过时信息
- ❌ 避免未经验证的内容

### 2. 相关性
- ✅ 与 Agent 领域高度相关
- ✅ 对 Agent 任务有帮助
- ❌ 避免无关内容

### 3. 完整性
- ✅ 内容完整，避免碎片化
- ✅ 包含必要的上下文
- ✅ 结构化程度高

### 4. 时效性
- ✅ 优先使用最新信息
- ✅ 标注内容时间戳
- ❌ 避免过时内容

## 五、不同 Agent 的格式示例

### 图像生成 Agent

```markdown
# 肖像摄影技巧

## 光线控制
- **黄金时刻**：日出后1小时和日落前1小时
- **柔光**：使用柔光板避免强烈直射光
- **反光板**：使用银色或白色反光板补光

## 构图技巧
- **三分法**：将画面分为九宫格，主体放在交叉点
- **浅景深**：使用大光圈（f/1.4 - f/2.8）虚化背景

## 提示词模板
professional portrait photography, soft natural lighting, shallow depth of field, 85mm lens, high quality, detailed
```

### 音乐生成 Agent

```markdown
# 和声进行

## 常用进行
- **卡农进行**：I-V-vi-IV
- **流行进行**：vi-IV-I-V

## 节奏型
- **4/4 拍**：适合大多数流行音乐
- **3/4 拍**：适合华尔兹风格

## 风格特征
- **轻爵士**：I-V-vi-IV，120 BPM，Bossa Nova 风格
```

### 代码生成 Agent

```markdown

## 实现步骤
1. 生成 Token

## 六、元数据要求

### 上传时添加元数据

```bash
curl -X POST ... \
  -F "file=@document.md" \
  -F "tags=[\"摄影\", \"技巧\"]" \
  -F "metadata={\"source\": \"专业教程\", \"author\": \"作者名\", \"date\": \"2024-01-01\"}"
```

### 元数据字段

| 字段 | 类型 | 说明 |
|------|------|------|
| source | string | 来源（如"官方文档"、"专业教程"） |
| author | string | 作者 |
| date | string | 日期 |
| category | string | 分类 |
| difficulty | string | 难度级别 |

## 八、常见问题

### Q: 可以上传 HTML 文件吗？

**A**: 不支持直接上传 HTML，需要先转换为 Markdown：
```bash
pandoc document.html -o document.md
```

### Q: 可以上传 Word 文档吗？

**A**: 不支持，需要先转换为 Markdown 或 PDF：
```bash
pandoc document.docx -o document.md
```

### Q: 长文档需要分段吗？

**A**: 系统会自动分段，但建议：
- 每个主题一个文档
- 文档长度 500-2000 字
- 使用清晰的标题层级

### Q: 可以上传图片吗？

**A**: 当前不支持图片，只支持文本内容。图片中的文字需要提取为文本。
