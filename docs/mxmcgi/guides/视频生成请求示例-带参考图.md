# 视频任务请求测试案例（带引用图片）

## 接口说明

- **业务入口**：`POST /api/v1/cgi/video/generate`（经 Gateway 代理到 mxmcgi 的 `/video/generate`）
- **认证**：请求头需带 `Authorization: Bearer <token>`，Gateway 会解析并转发 `x-user-id`
- **参考图**：每个 chunk 可带 `reference_image_url` 或 `input_reference`（图片 URL），会作为 Sora 2 的形象/场景参考

---

## 示例 1：单段视频（带参考图）

无 `chunks` 数组时，body 即为单个 chunk 的字段。

```bash
curl -X POST 'http://localhost:3000/api/v1/cgi/video/generate' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer YOUR_JWT_TOKEN' \
  -d '{
    "prompt": "一位穿白裙的女孩在森林小径上缓步行走，阳光透过树叶洒落，镜头缓慢跟随。",
    "chunk_seconds": 10,
    "reference_image_url": "https://your-cdn.com/character-ref.jpg",
    "label": "测试-单段-带参考图",
    "orientation": "portrait",
    "storeToMinio": true
  }'
```

**响应示例（单段）**：

```json
{
  "success": true,
  "data": {
    "taskId": "xxx-xxx-xxx",
    "status": "pending",
    "createdAt": "2025-02-07T12:00:00.000Z"
  }
}
```

## 示例 2：分镜批量（部分 chunk 带参考图）

有 `chunks` 数组时为批量；每个 chunk 可单独设置 `reference_image_url`。

```bash
curl -X POST 'http://localhost:3000/api/v1/cgi/video/generate' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer YOUR_JWT_TOKEN' \
  -d '{
    "chunks": [
      {
        "index": 1,
        "chunk_seconds": 10,
        "prompt": "清晨山谷，薄雾缭绕。喵小游背着小包沿山路缓行，远处溪水与鸟鸣。",
        "video_description": "清晨山谷，薄雾缭绕。喵小游背着小包沿山路缓行。",
        "characters_in_shot": ["喵小游"],
        "reference_image_url": "https://your-cdn.com/avatar-miaoxiaoyou.jpg"
      },
      {
        "index": 2,
        "chunk_seconds": 10,
        "prompt": "镜头切至山腰远景，喵小游继续向上攀登，阳光从云隙洒下。",
        "video_description": "山腰远景，喵小游继续攀登，阳光从云隙洒下。",
        "characters_in_shot": ["喵小游"]
      }
    ],
    "scriptType": "short-video-storyboard",
    "label": "分镜成片-测试",
    "orientation": "landscape",
    "storeToMinio": true
  }'
```

**说明**：

- 第一个 chunk 带 `reference_image_url`，会作为该段视频的形象/画面参考传给 Sora 2。
- 第二个 chunk 未带参考图，仅按 prompt 生成。
- `reference_image_url` 与 `input_reference` 二选一即可，后端优先用 `input_reference`，其次 `reference_image_url`。

**响应示例（批量）**：

```json
{
  "success": true,
  "data": {
    "parentTaskId": "parent-xxx",
    "batchId": "parent-xxx",
    "tasks": [
      { "taskId": "task-1", "chunkIndex": 0, "label": "分镜成片-测试1" },
      { "taskId": "task-2", "chunkIndex": 1, "label": "分镜成片-测试2" }
    ]
  }
}
```

## 示例 3：JSON 文件方式（便于 Postman / 脚本）

将 body 存为 `video-generate-with-ref.json`：

```json
{
  "chunks": [
    {
      "index": 1,
      "chunk_seconds": 10,
      "prompt": "室内咖啡厅，一位戴眼镜的男生坐在窗边看书，窗外下雨。",
      "reference_image_url": "https://example.com/character-ref-1.jpg",
      "characters_in_shot": ["李明"]
    }
  ],
  "scriptType": "short-video-storyboard",
  "label": "视频-带角色参考",
  "orientation": "portrait",
  "storeToMinio": true
}
```

请求：

```bash
curl -X POST 'http://localhost:3000/api/v1/cgi/video/generate' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer YOUR_JWT_TOKEN' \
  -d @video-generate-with-ref.json
```

---

## 字段说明（与参考图相关）

| 字段 | 位置 | 说明 |
|------|------|------|
| `reference_image_url` | 单段 body / 每个 chunk | 参考图 URL（角色形象或场景），会传给 Sora 2 的 input_reference |
| `input_reference` | 同上 | 与 reference_image_url 等价，后端优先使用 input_reference |
| `characters_in_shot` | 每个 chunk | 出场角色名，写作页「去生成视频」时会按此从任务角色中解析 reference_image_url 并写入 chunk |

本地调试时可将 `reference_image_url` 换为可公网访问的图片 URL，或使用项目 MinIO/OSS 上已有的图片 URL。
