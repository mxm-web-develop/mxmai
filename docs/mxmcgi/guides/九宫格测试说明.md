# 九宫格模式测试说明

## 测试步骤

### 1. 导入 Postman Collection

1. 打开 Postman
2. 点击 "Import" 按钮
3. 选择 `九宫格测试请求.postman_collection.json` 文件
4. 导入后，设置环境变量 `baseUrl`（默认：`http://localhost:3001`）

### 2. 设置 JWT Token

1. 先通过登录接口获取 JWT Token：
   ```bash
   curl -X POST http://localhost:3000/api/v1/account/login \
     -H "Content-Type: application/json" \
     -d '{"username":"your-username","password":"your-password"}'
   ```
2. 从响应中获取 `access_token`
3. 在 Postman 环境变量中设置 `token` 为获取到的 access_token
4. 所有请求会自动使用 `Authorization: Bearer {{token}}` header

**注意**: Gateway 会自动从 token 中提取 userId，无需手动传递 `x-user-id`

- **说明**: 查询graph类型的任务列表

## 常见问题

### Q: 任务一直处于 processing 状态？
A: 检查服务器日志，可能是图片切割或上传失败。查看 `[GraphTask]` 相关的日志。

### Q: 只看到部分子任务？
A: 检查是否有子任务创建失败的错误日志。系统会继续创建其他子任务，但失败的子任务不会出现在列表中。

### Q: 父任务仍然在列表中显示？
A: 检查 `SupabaseCGITaskRepository` 的 `findMany` 方法是否正确添加了过滤条件。

### Q: 图片切割失败？
A: 检查 sharp 库是否正确安装，以及图片URL是否可访问。
