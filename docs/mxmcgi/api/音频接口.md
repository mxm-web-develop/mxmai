# 音频生成接口文档

## 概述

音频生成接口提供文本转语音（TTS）和音色复刻功能，支持多种 MiniMax 语音合成模型。接口支持同步和异步两种模式，可根据模型类型和存储需求自动选择。

---

## 接口列表

### 1. 获取可用模型列表

获取所有可用的音频生成模型。

**接口信息**
- **方法**: `GET`
- **路径**: `/api/v1/audio/models`

**请求示例**

```bash
curl -X GET http://localhost:3000/api/v1/audio/models \
  -H "Authorization: Bearer <token>"
```

**响应示例**

```json
{
  "models": [
    {
      "name": "minimax-voice-cloning"
    },
    {
      "name": "minimax-speech-02-turbo"
    },
    {
      "name": "minimax-speech-02-hd-async"
    },
    {
      "name": "minimax-speech-2.6-hd-async"
    },
    {
      "name": "minimax-speech-2.5-hd-async"
    },
    {
      "name": "minimax-speech-2.5-turbo-async"
    },
    {
      "name": "minimax-speech-2.6-hd"
    },
    {
      "name": "minimax-speech-2.5-turbo"
    },
    {
      "name": "minimax-speech-2.5-hd"
    }
  ]
}
```

### 2. 生成音频

根据指定的模型生成音频，支持同步和异步两种模式。

**接口信息**
- **方法**: `POST`
- **路径**: `/api/v1/audio/:modelName`
- **模式**: 同步（部分模型）或异步任务

**路径参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| modelName | string | 是 | 模型名称，如 `minimax-speech-02-turbo` |

**查询参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| provider | string | 否 | 指定 provider（如 `deer`、`ppio`、`replicate`），不指定则使用默认 provider |
| storeToMinio | boolean | 否 | 是否存储到 MinIO（默认 `false`，通过 query 参数传递时使用字符串 `'true'`） |

**请求体参数**

根据模型类型不同，参数有所差异：

#### 通用参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| text | string | 条件必填 | 要合成的文本（语音合成模型必填） |
| prompt | string | 条件必填 | 要合成的文本（与 `text` 二选一） |
| storeToMinio | boolean | 否 | 是否存储到 MinIO（默认 `false`） |
| storageConfig | object | 否 | 自定义存储配置（覆盖默认路径） |

#### 音色复刻模型（`minimax-voice-cloning`）特有参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| audio_url | string | 是 | 参考音频 URL（用于音色复刻） |
| audioUrl | string | 是 | 参考音频 URL（与 `audio_url` 二选一） |

#### 语音合成模型参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| voice_setting | object | 否 | 音色设置 |
| voice_setting.speed | number | 否 | 语速 [0.5, 2]，默认 1.0 |
| voice_setting.vol | number | 否 | 音量 (0, 10]，默认 1.0 |
| voice_setting.pitch | number | 否 | 语调 [-12, 12]，默认 0 |
| voice_setting.voice_id | string | 条件必填 | 音色编号（与 `timbre_weights` 二选一必填） |
| voice_setting.emotion | string | 否 | 情绪：`happy`、`sad`、`angry`、`fearful`、`disgusted`、`surprised`、`neutral` |
| voice_setting.latex_read | boolean | 否 | 是否支持朗读 LaTeX 公式，默认 `false` |
| voice_setting.text_normalization | boolean | 否 | 英语文本规范化，默认 `false` |
| audio_setting | object | 否 | 音频设置 |
| audio_setting.sample_rate | number | 否 | 采样率：`8000`、`16000`、`22050`、`24000`、`32000`、`44100`，默认 `32000` |
| audio_setting.bitrate | number | 否 | 比特率：`32000`、`64000`、`128000`、`256000`，默认 `128000`（仅 mp3 格式生效） |
| audio_setting.format | string | 否 | 音频格式：`mp3`、`pcm`、`flac`、`wav`，默认 `mp3` |
| audio_setting.channel | number | 否 | 声道数：`1`（单声道）、`2`（立体声），默认 `1` |
| pronunciation_dict | object | 否 | 发音字典 |
| pronunciation_dict.tone | string[] | 否 | 替换发音，格式：`["燕少飞/(yan4)(shao3)(fei1)"]` |
| timbre_weights | array | 条件必填 | 音色混合权重（与 `voice_id` 二选一必填），最多 4 种音色 |
| timbre_weights[].voice_id | string | 是 | 音色 ID |
| timbre_weights[].weight | number | 是 | 权重 [1, 100] |
| stream | boolean | 否 | 是否流式输出，默认 `false` |
| stream_options | object | 否 | 流式输出选项 |
| stream_options.exclude_aggregated_audio | boolean | 否 | 流式最后一个 chunk 是否排除完整音频，默认 `false` |
| language_boost | string | 否 | 语言增强，如 `Chinese`、`English`、`auto` 等 |
| output_format | string | 否 | 输出格式：`url`、`hex`，默认 `hex`（非流式时生效） |
| voice_modify | object | 否 | 音色调整 |
| voice_modify.pitch | number | 否 | 音高调整 [-100, 100] |
| voice_modify.intensity | number | 否 | 强度调整 [-100, 100] |
| voice_modify.timbre | number | 否 | 音色调整 [-100, 100] |
| voice_modify.sound_effects | string | 否 | 音效：`spacious_echo`、`auditorium_echo`、`lofi_telephone`、`robotic` |

**同步模型**

以下模型支持同步返回（不创建任务，直接返回结果）：
- `minimax-speech-02-turbo`
- `minimax-speech-2.6-hd`
- `minimax-speech-2.5-turbo`
- `minimax-speech-2.5-hd`

**同步模式请求示例**

```bash
curl -X POST http://localhost:3000/api/v1/audio/minimax-speech-02-turbo \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "你好，这是一段测试文本",
    "voice_setting": {
      "voice_id": "female-shaonv",
      "speed": 1.0,
      "vol": 1.0
    },
    "audio_setting": {
      "format": "mp3",
      "sample_rate": 32000
    }
  }'
```

**同步模式响应示例**

```json
{
  "success": true,
  "model": "minimax-speech-02-turbo",
  "data": {
    "mediaUrls": ["https://example.com/audio.mp3"],
    "metadata": {
      "duration": 3.5,
      "format": "mp3"
    }
  }
}
```

**异步模式请求示例**

```bash
curl -X POST http://localhost:3000/api/v1/audio/minimax-speech-02-hd-async \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "这是一段较长的文本，需要异步处理",
    "voice_setting": {
      "voice_id": "female-shaonv"
    },
    "storeToMinio": true
  }'
```

**异步模式响应示例**

```json
{
  "success": true,
  "model": "minimax-speech-02-hd-async",
  "data": {
    "taskId": "task_xxx",
    "status": "pending",
    "createdAt": "2024-01-01T00:00:00Z"
  }
}
```

**任务结果查询**

异步模式下，通过 `GET /api/v1/cgi-tasks/:taskId` 查询任务状态和结果。

**结果格式**

```json
{
  "success": true,
  "data": {
    "id": "task_xxx",
    "type": "audio",
    "status": "completed",
    "result": {
      "mediaUrls": ["https://minio.example.com/user-123/audio/1234567890-abc123.mp3"],
      "storageInfo": {
        "keys": ["user-123/audio/1234567890-abc123.mp3"],
        "bucket": "user-media",
        "urls": ["https://minio.example.com/..."]
      },
      "metadata": {
        "duration": 5.2,
        "format": "mp3",
        "sampleRate": 32000
      }
    }
  }
}
```

## 模型说明

### 同步模型

- **minimax-speech-02-turbo**: 快速同步语音合成，适用于短文本
- **minimax-speech-2.6-hd**: 高质量同步语音合成
- **minimax-speech-2.5-turbo**: 快速同步语音合成（2.5 版本）
- **minimax-speech-2.5-hd**: 高质量同步语音合成（2.5 版本）

### 异步模型

- **minimax-speech-02-hd-async**: 高质量异步语音合成
- **minimax-speech-2.6-hd-async**: 高质量异步语音合成（2.6 版本）
- **minimax-speech-2.5-hd-async**: 高质量异步语音合成（2.5 版本）
- **minimax-speech-2.5-turbo-async**: 快速异步语音合成（2.5 版本）

### 音色复刻模型

- **minimax-voice-cloning**: 基于参考音频进行音色复刻

## 使用说明

### 1. 同步 vs 异步

- **同步模式**：适用于短文本（< 10000 字符），立即返回结果，不创建任务
- **异步模式**：适用于长文本或需要存储的场景，创建任务并返回 `taskId`，通过任务接口查询结果

### 2. 存储到 MinIO

设置 `storeToMinio: true` 时，生成的音频会自动存储到 MinIO，存储路径格式：
```
{userId}/audio/{timestamp}-{randomId}.{ext}
```

### 3. Provider 选择

- 可通过 `provider` 查询参数指定 provider
- 不指定时，系统自动选择支持该模型的 provider
- 支持的 provider：`deer`、`ppio`、`replicate`

---

## 完整接口路径映射

```
/api/v1/audio/models          → /audio/models
/api/v1/audio/:modelName      → /audio/:modelName
```

---

## 注意事项

1. **文本长度限制**：同步模型单次文本最大 10000 字符
2. **音色选择**：必须提供 `voice_id` 或 `timbre_weights` 之一
3. **流式输出**：部分模型支持流式输出，设置 `stream: true`
4. **权限控制**：只能访问自己创建的任务和音频文件
5. **存储路径**：可通过 `storageConfig` 自定义存储路径，否则使用默认路径
