# Text API 完整参数参考

## 接口地址

```
POST /text/:modelName
```

支持的模型：`claude-4.5-sonnet`, `deepseek-r1`, `gemini-2.5-flash`, `gemini-3-pro`, `gpt-5-nano`, `qwen3-235b-a22b`

---

## Provider（提供商）说明

### 支持的 Provider

| Provider | 说明 | 环境变量 | 特点 |
|----------|------|---------|------|
| `deerapi` / `deer` | DeerAPI | `DEERAPI_API_KEY`, `DEERAPI_BASE_URL` | 支持所有 Replicate 文本模型 + `qwen3-235b-a22b`，同步返回 |
| `replicate` | Replicate | `REPLICATE_API_TOKEN` | 支持所有文本模型，异步任务 |
| `ppio` | PPIO | `PPIO_API_KEY` | 目前不支持文本模型 |

### 默认 Provider 配置

在 `mxmcgi/.env` 文件中设置：

```bash
DEFAULT_PROVIDER=deerapi  # 或 replicate, ppio
```

**说明：**
- 如果不指定 `provider` 参数，系统会自动使用 `DEFAULT_PROVIDER` 配置的提供商
- `deerapi` 会自动映射为 `deer`
- 如果不设置 `DEFAULT_PROVIDER`，默认使用 `replicate`（向后兼容）

### 模型支持情况

| 模型 | Replicate | DeerAPI | PPIO |
|------|-----------|---------|------|
| `claude-4.5-sonnet` | ✅ | ✅ | ❌ |
| `deepseek-r1` | ✅ | ✅ | ❌ |
| `gemini-2.5-flash` | ✅ | ✅ | ❌ |
| `gemini-3-pro` | ✅ | ✅ | ❌ |
| `gpt-5-nano` | ✅ | ✅ | ❌ |
| `qwen3-235b-a22b` | ❌ | ✅ | ❌ |

### 指定 Provider

#### 方式一：通过查询参数（推荐）

```http
POST /text/gemini-2.5-flash?provider=deerapi
```

#### 方式二：使用默认 Provider

```http
POST /text/gemini-2.5-flash
# 自动使用 .env 中配置的 DEFAULT_PROVIDER
```

## 请求体参数

### 基础参数（所有模型通用）

| 参数 | 类型 | 必需 | 说明 | 示例 |
|------|------|------|------|------|
| `prompt` | string | ✅ | 生成提示词 | `"写一篇关于人工智能的文章"` |
| `negativePrompt` | string | ❌ | 负面提示词（不希望出现的内容） | `"不要使用专业术语"` |
| `outputFormat` | string | ❌ | 输出格式：`json`（默认）或 `stream`（流式输出） | `"stream"` |
| `enableCollection` | boolean | ❌ | 是否启用 collection 累积（默认 `true`）。流式输出时，如果设为 `false` 不会累积完整文本，节省内存 | `false` |

### 通用参数（大部分模型支持）

| 参数 | 类型 | 说明 | 默认值 | 示例 |
|------|------|------|--------|------|
| `temperature` | number | 温度参数，控制输出的随机性。值越高越随机，值越低越确定 | 模型默认值 | `0.7` |
| `max_tokens` / `max_output_tokens` | number | 最大输出 token 数 | 模型默认值 | `2048` |
| `system_prompt` / `system_instruction` | string | 系统提示词/指令 | - | `"你是一个专业的写作助手"` |
| `image` | string | 单张输入图片（用于多模态理解），支持 URL 或 Base64 data URI | - | `"https://example.com/image.jpg"` 或 `"data:image/jpeg;base64,..."` |
| `images` | string[] | 多张输入图片（用于多图理解） | - | `["https://example.com/img1.jpg", "https://example.com/img2.jpg"]` |

## 请求示例

### 1. 基础文本生成（JSON 格式）

```http
POST /text/gemini-2.5-flash
Headers:
  x-user-id: user123
Content-Type: application/json

{
  "prompt": "写一篇关于人工智能的简短介绍",
  "temperature": 0.7,
  "max_output_tokens": 1000
}
```

**响应：**
```json
{
  "success": true,
  "model": "gemini-2.5-flash",
  "result": {
    "text": "人工智能（Artificial Intelligence，简称AI）是计算机科学的一个分支...",
    "usage": {
      "prompt_tokens": 15,
      "completion_tokens": 250,
      "total_tokens": 265
    }
  }
}
```

---

### 2. 流式输出（Stream）

```http
POST /text/gemini-2.5-flash
Headers:
  x-user-id: user123
Content-Type: application/json

{
  "prompt": "写一篇关于人工智能的简短介绍",
  "outputFormat": "stream",
  "temperature": 0.7
}
```

**响应（Server-Sent Events 格式）：**
```
data: {"status":"start","text":""}

data: {"status":"streaming","text":"人工智能"}

data: {"status":"streaming","text":"（Artificial Intelligence"}

data: {"status":"streaming","text":"，简称AI）是计算机科学的一个分支..."}

data: {"status":"done","text":"完整文本...","collection":"完整文本..."}

data: [DONE]
```

## 响应格式

### JSON 格式响应

```json
{
  "success": true,
  "model": "gemini-2.5-flash",
  "result": {
    "text": "生成的完整文本...",
    "usage": {
      "prompt_tokens": 15,
      "completion_tokens": 250,
      "total_tokens": 265
    },
    "metadata": {
      "model": "gemini-2.5-flash",
      "provider": "deerapi"
    }
  }
}
```

### 流式输出响应（Server-Sent Events）

流式输出使用 Server-Sent Events (SSE) 格式，每个 chunk 包含：

```json
{
  "status": "streaming",  // "start" | "streaming" | "done"
  "text": "当前片段文本",
  "collection": "累积的完整文本（如果 enableCollection=true）"
}
```

最后会发送 `data: [DONE]` 表示流结束。

## 参数说明

### outputFormat（输出格式）

| 值 | 说明 | 适用场景 |
|---|------|---------|
| `json` | JSON 格式，返回完整文本 | 需要完整结果时使用 |
| `stream` | 流式输出，使用 Server-Sent Events | 需要实时显示生成过程时使用 |

### temperature（温度参数）

| 值范围 | 说明 | 适用场景 |
|--------|------|---------|
| `0.0 - 0.3` | 低温度，输出更确定、保守 | 事实性回答、代码生成 |
| `0.4 - 0.7` | 中等温度，平衡创造性和准确性 | 一般对话、内容创作 |
| `0.8 - 1.5` | 高温度，输出更随机、创造性 | 创意写作、头脑风暴 |
| `1.5+` | 很高温度，输出非常随机 | 实验性创作 |

### enableCollection（累积模式）

| 值 | 说明 | 适用场景 |
|---|------|---------|
| `true` | 累积完整文本（默认） | 需要完整文本时使用 |
| `false` | 不累积，只返回当前片段 | 流式输出时节省内存 |

## Provider 选择指南

### 如何选择 Provider

1. **DeerAPI（推荐）**：
   - ✅ 支持所有 Replicate 文本模型
   - ✅ 额外支持 `qwen3-235b-a22b`
   - ✅ 同步返回，响应速度快
   - ✅ 支持流式输出
   - ⚠️ 需要配置 `DEERAPI_API_KEY` 和 `DEERAPI_BASE_URL`

2. **Replicate**：
   - ✅ 支持所有文本模型
   - ✅ 异步任务，适合长时间生成
   - ⚠️ 需要配置 `REPLICATE_API_TOKEN`
   - ⚠️ 不支持 `qwen3-235b-a22b`

3. **PPIO**：
   - ❌ 目前不支持文本模型

### Provider 使用示例

#### 示例 1：使用默认 Provider（推荐）

```http
POST /text/gemini-2.5-flash
# 自动使用 .env 中配置的 DEFAULT_PROVIDER
```

#### 示例 2：明确指定 Provider

```http
POST /text/gemini-2.5-flash?provider=deerapi
# 使用 DeerAPI，即使 DEFAULT_PROVIDER=replicate
```

#### 示例 3：使用仅 DeerAPI 支持的模型

```http
POST /text/qwen3-235b-a22b?provider=deerapi
# qwen3-235b-a22b 只有 DeerAPI 支持，必须指定 provider=deerapi
```

#### 示例 4：Provider 自动选择

```http
POST /text/gemini-3-pro
# 如果 DEFAULT_PROVIDER=deerapi，自动使用 DeerAPI
# 如果 DEFAULT_PROVIDER=replicate，自动使用 Replicate
```

## 最佳实践

1. **选择模型**：
   - 需要高质量推理：`claude-4.5-sonnet`、`gemini-3-pro`
   - 需要快速响应：`gemini-2.5-flash`、`gpt-5-nano`
   - 需要推理能力：`deepseek-r1`、`gemini-2.5-flash`（启用思考模式）
   - 需要 Qwen 模型：`qwen3-235b-a22b`（仅 DeerAPI 支持）

2. **选择 Provider**：
   - 推荐使用 DeerAPI：支持所有模型，响应速度快
   - 需要特定模型时：根据模型支持情况选择 Provider
   - 使用默认 Provider：在 `.env` 中配置 `DEFAULT_PROVIDER`，简化调用

3. **输出格式选择**：
   - 需要完整结果：使用 `outputFormat: "json"`
   - 需要实时显示：使用 `outputFormat: "stream"`

4. **温度参数调整**：
   - 事实性任务：`temperature: 0.1 - 0.3`
   - 创意任务：`temperature: 0.7 - 1.0`
   - 实验性创作：`temperature: 1.0+`

5. **Token 限制**：
   - 根据任务复杂度设置合适的 `max_tokens`
   - 注意不同模型的最大 token 限制不同

6. **多模态使用**：
   - 单张图片：使用 `image` 参数
   - 多张图片：使用 `images` 数组
   - 支持 URL 和 Base64 两种格式
