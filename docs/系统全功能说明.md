# 系统全功能说明

用于在 **Web 调试端** 进行全接口联调，并定位 **提示词工程** 配置以便优化。

---

## 一、模块与 API 总览

所有接口经 **Gateway**（默认 `http://localhost:3000`）对外暴露，认证方式：`Authorization: Bearer <JWT>`（登录接口除外）。

| 模块 | Gateway 路径 | 后端服务 | 说明 |
|------|--------------|----------|------|
| 账户 | `POST /api/v1/account/login` 等 | mxmauth | 登录、注册、个人资料、设置 |
| 角色 | `GET/POST/PUT/DELETE /api/v1/characters` 等 | mxmcgi | 角色 CRUD、关联图片/音频、从写作/大纲保存角色 |
| 写作 | `POST /api/v1/writing/outline`<br>`POST /api/v1/writing/generate`<br>`POST /api/v1/writing/rewriting`<br>`POST /api/v1/writing/polishing`<br>`GET /api/v1/writing/getformOptions` 等 | mxmcgi | 大纲、文章/分镜/口播/歌词等写作、改写、润色、表单选项 |
| 任务 | `GET /api/v1/cgi-tasks/:taskId`<br>`GET /api/v1/cgi-tasks`<br>`POST /api/v1/cgi-tasks/:taskId/cancel` 等 | mxmcgi | 异步任务查询、列表、取消、恢复、重试 |
| 视频 | `POST /api/v1/cgi/video/generate`<br>`GET /api/v1/cgi/video/getformOptions` 等 | mxmcgi | 视频生成（含分镜成片）、表单选项 |
| 图文 | `POST /api/v1/cgi/graph/photograph`<br>`POST /api/v1/cgi/graph/design`<br>`POST /api/v1/cgi/graph/painting`<br>`GET /api/v1/cgi/graph/getformOptions` 等 | mxmcgi | 摄影/设计/绘画等图像生成、表单选项 |
| 文本 | `POST /api/v1/cgi/text/:modelName` | mxmcgi | 通用文本生成（按模型） |
| 音频 | `POST /api/v1/cgi/audio/:modelName` | mxmcgi | TTS、音乐等音频生成 |
| 知识库 | `GET/POST/PUT/DELETE /api/v1/knowledge/bases`<br>`POST /api/v1/knowledge/bases/:id/documents`<br>`POST /api/v1/knowledge/bases/:id/search` 等 | mxmcgi | 知识库 CRUD、文档管理、检索 |
| 媒体 | `GET /api/v1/media/graph/:taskId`<br>`GET /api/v1/media/video/:taskId`<br>`GET /api/v1/media/writing/:taskId`<br>`GET /api/v1/media/audio/:taskId` 等 | mxmcgi | 按任务获取生成结果（图/视频/写作/音频） |
| 上传 | `POST /api/v1/cgi/upload/temp` | mxmcgi | 临时文件上传 |

## 二、写作与大纲（提示词相关）

- **入口**：`/api/v1/writing/outline`、`/api/v1/writing/generate`、`/api/v1/writing/rewriting`、`/api/v1/writing/polishing`
- **表单选项**：`GET /api/v1/writing/getformOptions?writing_type=xxx&outline_type=xxx&lang=zh`

**提示词工程位置**（rules / outputformat / 格式说明）：

| 类型 | 配置文件路径 | 说明 |
|------|--------------|------|
| 写作类型配置 | `mxmcgi/src/core/writing/wtconfigs/` | 各类型的 `rules`、`outputformat`、`getFormOptions` |
| 文章 | `wtconfigs/articles.ts` | 科技文章 / 故事小说 / 学术论文 等细分 |
| 分镜脚本 | `wtconfigs/storyboard-scripts.ts` | 分镜 JSON 规则与输出格式、多镜头说明 |
| 口播稿 | `wtconfigs/voice-scripts.ts` | 口播稿规则与 TTS 格式 |
| 歌词 | `wtconfigs/lyrics.ts` | 歌词与 Suno 格式 |
| 大纲 | `wtconfigs/outlines.ts` | 大纲生成规则与结构 |
| 其他 | `wtconfigs/lyrics.ts`、`media-post.ts`、`reviews.ts`、`resumes.ts` | 对应类型的 rules/outputformat |

**加载入口**：`mxmcgi/src/core/writing/wtconfigs/index.ts`  
- `getWritingTypeConfig(writingType)`  
- `buildPromptWithConfig(writingType, userPrompt)`  
- `getWritingTypeRules` / `getWritingTypeOutputFormat`  
- `getWritingFormOptionsForType`

## 三、图文生成（提示词相关）

- **入口**：`POST /api/v1/cgi/graph/photograph`、`/design`、`/painting`（或按模型 `POST /api/v1/cgi/graph/:modelName`）
- **表单选项**：`GET /api/v1/cgi/graph/getformOptions?graphType=xxx&type=xxx&lang=zh`

**提示词工程位置**（rules / outputformat / 业务参数）：

| 业务类型 | 配置文件路径 | 说明 |
|----------|--------------|------|
| 摄影 photograph | `mxmcgi/src/core/graph/graphconfigs/photograph/` | portrait、landscape、cinematic、commercial、documentary |
| 设计 design | `graphconfigs/design/` | 3d、manual、poster、icon、coverImage、ui-design |
| 绘画 painting | `graphconfigs/painting/` | illustration、comic、conceptArt、cartoon |

每个子类型通常有：`rules`、`outputformat`、以及 `formOptions.ts`（表单与参数说明）。  
**加载入口**：`mxmcgi/src/core/graph/graphconfigs/getFormOptions.ts`（`getFormOptionsForType`）。

---

## 四、视频生成

- **入口**：`POST /api/v1/cgi/video/generate`（单段或 chunks 批量）
- **表单选项**：`GET /api/v1/cgi/video/getformOptions?lang=zh`
- **提示词**：视频由「分镜脚本」的 chunks 驱动，分镜的提示词规则在 **写作 - storyboard-scripts**（见第二节）。

---

## 五、角色

- **CRUD**：`GET/POST /api/v1/characters`，`GET/PUT/DELETE /api/v1/characters/:id`
- **扩展**：`POST /api/v1/characters/:id/link-image-task`、`/link-audio-task`  
  `POST /api/v1/characters/save-from-writing`、`/save-from-outline`  
  `POST /api/v1/characters/generate`（角色生成）
- 角色带 `appearance.reference_images` / `clothing_style.reference_images`，用于写作与视频成片的形象参考。

---

## 六、知识库

- ** bases**：`GET /api/v1/knowledge/bases`、`POST /api/v1/knowledge/bases`、`GET/PUT/DELETE /api/v1/knowledge/bases/:id`
- **文档**：`POST /api/v1/knowledge/bases/:id/documents`（上传/解析）、`GET /api/v1/knowledge/bases/:id/documents`、`DELETE /api/v1/knowledge/documents/:id`
- **检索**：`POST /api/v1/knowledge/bases/:id/search`
- 写作/大纲可带 `knowledgeBase` 参数，将检索结果注入上下文，影响生成效果。

## 七、Web 调试端与功能对应

| 调试页 | 主要接口 | 提示词优化关联 |
|--------|----------|----------------|
| 登录 | 配置 Base URL、登录 | - |
| 角色 | 角色列表、创建角色 | - |
| 大纲 | POST writing/outline | wtconfigs/outlines.ts |
| 写作 | POST writing/generate | wtconfigs/*.ts（含 storyboard-scripts） |
| 任务 | GET cgi-tasks/:id | 轮询结果，用于后续步骤 |
| 视频 | POST cgi/video/generate | 分镜来自写作，提示词见 storyboard-scripts |
| 图文 | POST cgi/graph/* | graphconfigs/photograph|design|painting |
| 文本 | POST cgi/text/:modelName | 通用模型，无独立配置表 |
| 音频 | POST cgi/audio/:modelName | 按模型，配置在 mxmcgi 音频模块 |
| 知识库 | GET/POST knowledge/bases、documents、search | - |
| 媒体 | GET media/graph|video|writing|audio/:taskId | - |
| 表单选项 | GET writing|video|graph getformOptions | 与各类型 rules/表单一致，可对照改提示词 |
| 提示词工程 | 说明 + 配置文件路径索引 | 直接打开 wtconfigs、graphconfigs 进行编辑 |

## 八、提示词优化流程建议

1. **定位**：根据业务类型在「表单选项」或「提示词工程」页找到对应配置文件路径（见上表）。
2. **修改**：编辑 `mxmcgi/src/core/writing/wtconfigs/*.ts` 或 `mxmcgi/src/core/graph/graphconfigs/**/*.ts` 中的 `rules`、`outputformat`、表单描述等。
3. **验证**：在 Web 调试端对应页（大纲/写作/图文/视频等）发起请求，查看输出是否符合预期；必要时用「任务」页轮询并查看完整结果。
4. **迭代**：结合生成结果微调 rules 与 outputformat，必要时调整表单选项（getformOptions）以暴露/隐藏参数。
