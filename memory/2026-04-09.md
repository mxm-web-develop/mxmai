## Chrome Headless PDF导出进程挂起问题（重要教训）

**症状**：小红书内容管线在"截图环节"卡死，Chrome进程不退出

**根本原因**：
- 旧版 `--headless` 在 macOS 上不会自动退出
- 缺少 `--timeout` 参数，Chrome 无限等待
- 缺少 `--no-sandbox` 在某些环境下无法正常运行

**解决方案**（已更新到 skill）：
```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless=new --disable-gpu --no-sandbox --timeout=30000 \
  --print-to-pdf=output.pdf --print-to-pdf-no-header \
  --virtual-time-budget=10000 file:///path/to/input.html
```

**备用方案**：加 `--run-all-compositor-stages-before-draw --disable-features=VizDisplayCompositor`

**涉及skill**：`xiaohongshu-pdf-screenshot` ✅ + `xiaohongshu-content-pipeline` ✅ 均已更新
