# SuperMXMai PRODUCT.md

## Register

**product** — authenticated app UI / creative console. Design serves the task; familiarity over novelty.

## Users & purpose

- Creators and ops users producing writing, images, audio, music, video via Task V2 and Smartflow.
- Primary jobs: configure generation, run workflows, manage assets, chat with an AI assistant that composes platform businesses.
- Context: desktop-first console with Ant Design + Tailwind; accent aligns to sky-600.

## Personality

Clear · Capable · Calm. Tool disappears into the creative task. No marketing theatrics on app surfaces.

## Anti-references

- Purple glow / “AI chatbot” glassmorphism
- Cream paper editorial skins on product screens
- Decorative motion that delays task flow
- Nested card stacks in heroes or empty states

## Design principles

1. Restrained color: sky accent for primary actions and selection only.
2. One UI sans family; fixed rem scale; dense but readable.
3. Motion = state feedback (150–250ms); respect `prefers-reduced-motion`.
4. Empty states teach the next action; don’t decorate emptiness.
5. Reuse existing tokens (`--agent-chat-*`, Ant Design patterns) before inventing components.
