# 知识库（前端模块）

产品名：**知识库**。本目录存放知识库页面相关 UI（文件夹树、软链、标签卡、解析进度等）。

| 概念 | 说明 |
|------|------|
| 知识库 | 模块名（导航 / 页面 / `@`） |
| 文件夹 | 知识库内的组织单位 |
| HTTP | 仍走 `/api/v1/virtual-folder-index/*`（后端路径未改） |
| 表单字段 | 提交音色克隆等仍可能带 `virtual_folder_id`（后端字段名） |

勿再引入 `VirtualFolder*` 符号或「虚拟文件夹」用户文案。底层向量库 `knowledge_base_id` 是实现细节，不对用户展示为另一套「知识库产品」。
